# 砖型图选股任务

> ⚠️ 本文件是唯一权威评分标准，`memory/砖型图选股标准化流程.md` 为辅助说明，如有冲突以本文件为准。

## 任务描述
分析条件选股截图，识别股票代码，获取K线数据，按砖型图+B1+B2+J值+均线+热门概念评分，输出飞书文档

---

## 评分标准（100分制）⭐ 唯一权威版本

> 来源：砖型图条件股评分（2026-03-04确认版）
> **评分上限：100分**

| 指标 | 分数 | 条件 |
|------|------|------|
| 涨停 | +30分 | 涨幅 > 9% |
| 涨幅5-9% | +15分 | 5% ≤ 涨幅 < 9% |
| MA20向上 | +10分 | 20日均线今日 > 昨日 |
| 多头排列 | +10分 | MA5 > MA10 > MA20 |
| 放量 | +10分 | 今日成交量 > 昨日 × 1.5 |
| 砖型图走强 | +20分 | 今日砖型值 > 昨日砖型值 |
| 砖型值>100 | +5分 | 砖型值 > 100 |
| B1信号 | +20分 | 见B1公式（library.py） |
| B2信号 | +15分 | 见B2公式（library.py） |

> ❌ 已废除：J值超卖+10分、热门概念+5/10分、放量1.5x+15分（与放量+10分重复）
> 注意：评分超过100分时截断为100分

## B1/B2 公式（来自 indicators/library.py）

### B1（必须严格按公式，不能自己编！）
- 趋势白线 >= 大哥黄线（多头）
- VOL < 20日最高量 × 0.416（缩量）
- J < 14（KDJ超卖）
- RSI < 23（RSI超卖）
- 振幅 >= 15%（异动）

### B2（来自 library.py check_b2 函数）
- 昨日J值 < 0
- 今日涨幅 > 3.95%
- 今日成交量 > 昨日成交量 × 1.5
- 今日J值 < 55

## 北交所处理规范

北交所股票代码（920xxx、4开头等），腾讯API无法直接获取：

```python
def get_market_prefix(code):
    """获取API市场前缀"""
    if code.startswith('6'):
        return 'sh'
    elif code.startswith('0') or code.startswith('3'):
        return 'sz'
    elif code.startswith('9') or code.startswith('4'):
        # 北交所 - 腾讯API不支持，降级用浏览器
        return 'bj'  # 标记为北交所，走浏览器分支
    else:
        return 'sz'
```

**处理逻辑**：
1. 识别到 `bj` 市场代码 → 自动切换浏览器获取（agent-browser skill）
2. 浏览器目标：`https://quote.eastmoney.com/center/gridlist.html#bj_a_board`
3. 北交所涨停幅度为30%（非10%），评分时涨停条件改为 > 28%

## 关键原则（必须遵守！）

1. **浏览器操作必须用 agent-browser skill**
   - 路径：`~/.agents/skills/agent-browser/`
   - **禁止使用 OpenClaw 内置 browser 工具**

2. **腾讯API为首选**
   - 涨幅计算：**禁止使用腾讯API实时涨幅字段**（数据严重错误！）
   - 必须用K线计算：`(今日收盘价 - 昨日收盘价) / 昨日收盘价 * 100`
   - K线接口：`https://web.ifzq.gtimg.cn/appstock/app/fqkline/get?param={code},day,,,120,qfq`

3. **图片识别必须用 minimax-understand-image skill**
   - 禁止使用 OpenClaw 内置 image 工具

## 执行流程

1. **截图识别** → minimax-understand-image skill 识别股票代码
2. **市场分类** → 区分沪深（sh/sz）和北交所（bj）
3. **K线数据** → 腾讯API批量获取（北交所走浏览器）
4. **涨幅计算** → K线收盘价计算真实涨幅（禁用实时字段）
5. **指标计算** → 砖型图、J值、RSI、B1、B2、均线（library.py）
6. **概念数据** → agent-browser skill + MiniMax识别
7. **评分计算** → 100分制，上限100分
8. **输出检查** → 确认11列完整（含排名），涨停/非涨停各TOP10
9. **飞书文档** → 格式化输出，标注数据来源

## 复盘流程

### 时间规则
- 同日：当天选股 → 次日收盘后复盘
- 跨周：周五选股 → 下周一复盘（中间隔周末）
- **复盘日期 = 今日日期，选出日期 = 上一个交易日**

### 复盘步骤
1. 找到上一个交易日的选股记录（`memory/patrol/YYYY-MM-DD.md`）
2. 用K线查询复盘日的收盘价（必须是收盘价，不是实时价！）
3. 计算涨幅：`(复盘日收盘 - 选出日收盘) / 选出日收盘 * 100`
4. 输出复盘表格（含选出日收盘、复盘日收盘、涨幅、表现评价）
