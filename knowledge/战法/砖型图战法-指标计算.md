## ⚠️ 重要教训（必须牢记！）

### 教训1：涨幅计算必须用K线！
- **错误**: 使用腾讯API实时涨幅字段（如320%、192%）
- **正确**: 用K线计算真实涨幅 = (今日收盘价 - 昨日收盘价) / 昨日收盘价 × 100
- **原因**: API实时涨幅字段数据错误
- **教训**: 一个月内犯了3次同样的错误！必须用K线数据！

### 教训2：B1/B2判断不能自己编！
- **错误**: B1=连续3天上涨+放量，B2=多头排列+放量
- **正确**: 必须用library.py里的公式
- **B1公式**:
  - 趋势白线 >= 大哥黄线
  - VOL < 20日最高量 × 0.416 (缩量)
  - J < 14 (KDJ超卖)
  - RSI < 23 (RSI超卖)
  - 振幅 >= 15% (异动)
- **B2公式**:
  - 昨日J值 < 0
  - 今日涨幅 > 3.95%
  - 今日成交量 > 昨日成交量 × 1.5
  - 今日J值 < 55

### 教训3：所有指标都可以用腾讯API计算！
- **错误**: 说"砖型图指标无法获取"
- **正确**: 腾讯API K线数据 + library.py函数都可以计算
- **需要的函数**: calc_kdj, calc_rsi, calc_ma, calc_ema, calc_zhuantxing

### 教训4：输出必须完整！
- **错误**: 分类时减少字段（J值、RSI等）
- **正确**: 每次输出必须包含所有字段
- **必须字段**: 代码,名称,涨幅,砖型,J,RSI,B信号,评分,指标明细,概念

## 指标计算公式 (来自indicators/library.py)

### 砖型图
```
VAR1A = (HHV(HIGH,4) - CLOSE) / (HHV(HIGH,4) - LLV(LOW,4)) * 100 - 90
VAR2A = EMA(VAR1A, 4) + 100
VAR3A = (CLOSE - LLV(LOW,4)) / (HHV(HIGH,4) - LLV(LOW,4)) * 100
VAR4A = EMA(VAR3A, 6)
VAR5A = EMA(VAR4A, 6) + 100
VAR6A = VAR5A - VAR2A
砖型图 = IF(VAR6A > 4, VAR6A - 4, 0)
```

### KDJ (J值)
```
RSV = (CLOSE - LLV(LOW,9)) / (HHV(HIGH,9) - LLV(LOW,9)) * 100
K = EMA(RSV, 3)
D = EMA(K, 3)
J = 3*K - 2*D
```

### RSI
```
RSI = 100 - 100 / (1 + EMA(GAIN,3) / (EMA(LOSS,3) + 0.001))
```

### 趋势线
- **趋势白线**: EMA(EMA(C,10),10)
- **大哥黄线**: (MA14 + MA28 + MA57 + MA114) / 4
- **多头**: 趋势白线 >= 大哥黄线
