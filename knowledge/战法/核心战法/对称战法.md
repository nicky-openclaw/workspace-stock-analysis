# 独门对称战法（10.22）

**直播日期**：2025年10月22日  
**系列名称**：独门对称战法  
**核心定义**：基于杨振宁「对称性支配相互作用」理论，结合多空守恒原理，寻找走势不完美（守恒被破坏）的位置进行交易的核心战法。**只在守恒被破坏的位置才有交易价值**。

---

## 一、核心理念

### 1.1 对称性原理
世界上所有事物都遵循对称性原则，多空双方的能量守恒。当守恒被打破时，就会产生交易机会。

> **核心口诀**：走势必对称，但要找不完美的走势

### 1.2 三种对称类型

| 对称类型 | 定义 | 应用场景 |
|---------|------|---------|
| **时间对称** | 上升周期必然对应下降周期，加息必然对应降息 | 择时，判断市场整体所处阶段 |
| **空间对称** | 上涨后下跌的空间对称（直接对称/间接对称） | 选股，寻找完美标的 |
| **形态对称** | 轴对称（水平线为轴）/ 中心对称（中心点旋转） | 入场点判断 |

### 1.3 守恒被破坏
- **核心概念**：多空双方能量守恒被打破的位置才有交易价值
- **标志信号**：
  - 原本应该下跌的走势突然走横或上涨
  - 斜率发生明显改变
  - 横盘后出现突破K线

## 二、识别条件（八步法）

1. 打开股票K线图，先画N型结构，找到低点和高点
2. 观察走势是直接对称还是间接对称，判断斜率是否发生变化
3. 寻找守恒被破坏的位置，即原本应该下跌却走横或上涨的位置
4. 确认是否出现B1信号（KDJ的J值勾起大负值）
5. 结合白线（短期趋势线）和黄线（多空判断线）判断位置
6. 观察是否走横，走横是最有价值的买入点
7. 设置止损位，一般设在入场K线的最低点下方
8. 等待对称完美后进行放飞

## 三、交易规则

### 3.1 买入时机

| 规则 | 触发条件 |
|------|---------|
| **规则1** | B1买入需配合三个条件：守恒被破坏 + 走横 + KDJ的J值勾起大负值 |
| **规则2** | 间接对称的位置，即A股起来后回调只回一半被多头顶上去的位置 |
| **规则3** | 走横的位置最有价值，等待横盘后出现B1信号 |
| **规则4** | 斜率发生改变的位置，原本应该下跌但没有下跌 |
| **规则5** | 底部走横后出现放量大阳线打破平衡的位置 |
| **规则6** | 下跌趋势中连续下跌后出现不创新低的K线 |
| **规则7** | 突破前高后回踩不破前高的位置 |
| **规则8** | B2突破时结合对称理论判断真假突破 |

### 3.2 止损规则

1. 止损位置设在入场K线的最低点下方
2. 如果跌破白线（短期趋势线）必须止损
3. 如果走横后跌破关键支撑位要止损
4. A股杀下来的票买错第二天必须止损
5. 买入后两天内没有出现预期走势要止损
6. 出现S1信号时是止损或止盈的信号
7. 斜率改变后走坏要果断止损

### 3.3 目标位设定
- 对称理论本身不设固定目标位，依靠走横判断和B1B2信号判断何时放飞
- 当出现4分之3音量线时要警觉是否要开始对称下跌
- 当走势完美对称后要放飞，不要恋战

## 四、关键原则（20条）

1. 只在守恒被破坏的位置才有交易价值
2. 走势必对称，但要找不完美的走势
3. A股杀下来的票不要碰，除非第二天涨停否则必须走
4. 走横是最有价值的买入点
5. 斜率改变是多空力量失衡的重要信号
6. 时间对称用于择时，空间对称用于选股，形态对称用于入场
7. B1买入必须配合守恒被破坏、走横、J值勾起大负值三个条件
8. 对称完美后要放飞，不要期待吃到全部利润
9. 小级别对称要服从大级别对称
10. 空间越大、时间越长的对称确定性越强
11. 横盘期间没有交易价值，要等打破平衡的K线出现
12. 看图要画N型结构，找高低点
13. 放量突破和缩量回调都是信号
14. 右侧交易一律是短线，必须带止损
15. 不要在横盘震荡区间频繁交易
16. 不要听任何内幕消息，坚持自己的交易系统
17. 心态管理比技术更重要
18. 宁可错过，不要做错
19. 持续学习但不要过度学习
20. 实战中积累经验，三到五年才能真正掌握

## 六、失败场景

1. 买入后连续横盘不走趋势，浪费资金时间成本
2. A股杀下来的票买入后继续下跌，第二天的涨停预期落空
3. 走横后买入但继续横盘，没有等来上涨
4. 对称完美后没有及时放飞，利润回吐
5. 小级别对称失败，被大趋势吞没
6. 空间和时间不够的对称交易，胜率低
7. 逆势操作，在下跌趋势中找对称买点
8. 频繁交易，横盘期间不断操作

## 八、教学价值总结

**独门对称战法**的核心价值在于：

1. **理论高度**：引用杨振宁物理学理论，将股市波动提升到自然法则高度
2. **实战精要**：强调"守恒被破坏"是唯一交易信号，过滤无效行情
3. **三重应用**：
   - 时间对称 → 择时（判断市场整体阶段）
   - 空间对称 → 选股（寻找完美标的）
   - 形态对称 → 入场（精确买入点）
4. **纪律强调**：交易心理建设和止损纪律是战法成功的前提

> **核心口诀**：只在守恒被破坏的位置才有交易价值
