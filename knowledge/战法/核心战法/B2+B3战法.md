**直播日期**：2025年10月6日  
**系列名称**：B2+B3战法  
**讲师**：大雷翁小菜鸟  
**核心定义**：B2是第二买点，即确认B1的第一根放量中长阳；B3是第三买点，即B2之后的中继小阳线。核心讲解N型结构后的第二、第三个入场点及三大暴力图形（平行重炮、灾后重建、跃跃欲试）。

---

## 一、核心逻辑：B1-B2-B3三件套

### 1.1 B1定义
**B1** = 不同时间周期下的阶段低点位置（KDJ J值13以下）

- 寻找跨周期的阶段性底部结构
- 守恒被破坏+走横+KDJ勾拐头大负值时可买入
- B1可以开超市轻仓试错
- 盈亏比最高

### 1.2 B2定义
**B2** = 不同时间周期下的B1低点确认阳线位置

- 确认B1的那根阳线
- B2涨幅必须大于等于4%
- B2必须比前一交易日放量
- B2的勾必须小于55，有上涨空间
- 无上影线的B2是最好的
- B2买完只给两天时间，必须两天内大涨
- B2不建议开超市

### 1.3 B3定义
**B3** = 不同时间周期下持续上涨波段内的B2上涨后的中继位置

- 确认B2的中继小阳线
- 缩量且股价站上B2
- B3确定性最高但需要反应快
- 不确定性较大

### 1.4 三件套核心原则

| 原则 | 说明 |
|------|------|
| 层层筛选 | B2确认B1，B3确认B2，层层确认提高胜率 |
| 一个踩一个 | B1、B2、B3必须一个踩一个形成三件套 |
| 底分型不稳定 | 底分型不稳定必须靠B3确认 |
| 低位不停留 | 低位不可能停留太久让散户超回来，必须快速拉上去 |

## 二、识别条件（8步法）

### B2买入的五个条件

1. **B1的KDJ勾拐头** - 确认B1企稳
2. **B2涨幅大于4%** - 确认力度足够
3. **B2比前一交易日放量** - 确认主力进场
4. **B2当天的KDJ勾小于55** - 确认有上涨空间
5. **B2无上影线最好** - 确认当天强势

### B3确认条件

1. B2后出现缩量小阳线
2. 股价站上B2高点
3. 白线在黄线之上

## 三、三大暴力图形

### 3.1 战法一：平行重炮

**特征**：
- 两根及以上大阳线相对平行位置
- 放量长阳突破
- 缩量回调不破支撑
- 快速脱离成本区

**条件**：
- 至少两门重炮
- 放量突破
- 回调缩量

**案例**：中坚科技、百普赛斯、南亚新材、世运电路、中富电路、四会富士、国盛金控、国义招标、财富趋势

### 3.2 战法二：灾后重建

**特征**：
- 连续拉升后缩量跌到黄线
- 缩量回踩黄线
- 再次放量长阳收回
- 连续拉升前的最后震仓

**条件**：
- 必须打到黄线
- 缩量回踩
- 放量长阳收回

**案例**：晶科科技、美迪西、英飞特、安德利

### 3.3 战法三：跃跃欲试

**特征**：
- 横盘期间放量大阳线
- 红肥绿瘦
- 多次假突破后真突破
- 事不过三

**条件**：
- 横盘整理
- 出现中大阳线
- 多次验证

**案例**：鼎捷数智、潮宏基、海天瑞生、英飞特、路桥信息、幸福蓝海、奔朗新材、新瀚新材

## 四、双线战法补充

### 白线黄线关系

| 关系 | 含义 |
|------|------|
| 白线金叉黄线 | 上涨趋势确立概率大，确立信号 |
| 白线死叉黄线 | 最后的离场时机 |
| 白线与黄线要死而未死叉 | 配合N型结构不破及J大负值，为极限买点 |
| 白线与黄线区间 | N型上涨趋势中的高容错率买入区 |

### 均线参数
- 常用参数：14/28/57/114
- 长期参数：MA60、MA120、MA250

### 量价关系
- **放量金叉后缩量回踩黄线**：连续拉升前的最后震仓动作，具有极大的交易价值
- **横盘期间红肥绿瘦**：好事
- **高位放量**：不是好事，顶部无量最好

## 五、交易规则

### 5.1 买入时机

| 买点 | 条件 |
|------|------|
| B1买入 | 守恒被破坏+走横+KDJ勾拐头大负值 |
| B2买入 | 涨幅大于4%+放量+勾小于55+无上影线最好 |
| B3买入 | B2后缩量小阳线，股价站上B2 |
| 平行重炮 | 两门以上重炮回调后突破 |
| 灾后重建 | 缩量回踩黄线后放量长阳 |
| 跃跃欲试 | 横盘期间放量大阳突破 |

### 5.2 止损规则

| 买点 | 止损位 |
|------|--------|
| B1止损 | 买入K线最低点下方3-5价位，或N型结构前低 |
| B2止损 | 设在之前N型结构低点，或B2阳线最低点 |
| B3止损 | 不破B3最低点，或不破B2中长阳中间价位 |
| 20厘米B2止损 | 设在大阳线中间位置 |
| 4-10厘米B2止损 | 设在突破阳线最低点 |
| 白线止损 | 跌破白线走人 |

### 5.3 目标位设定
- 沿白线持有不动
- 缩量回踩黄线是加仓机会
- 放量突破后看新高

## 六、关键原则汇总

1. B1、B2、B3必须一个踩一个形成三件套
2. B2确认B1，B3确认B2，层层筛选确认
3. B2的勾必须小于55，有上涨空间
4. B2涨幅必须大于等于4%
5. B2必须比前一交易日放量
6. 无上影线的B2是最好的
7. B1可以开超市轻仓试错，B2不建议开超市
8. B2买完只给两天时间，必须两天内大涨
9. B3确定性最高但需要反应快
10. B1盈亏比最高，B2其次，B3不确定性大
11. 白线是短期趋势线，黄线是大哥成本线
12. 股价必须站上黄线才能参与
13. 放量金叉后缩量回踩黄线交易价值极大
14. 横盘期间红肥绿瘦是好事
15. 高位放量不是好事，顶部无量最好
16. 止损必须严格执行，不能扛单
17. 做B1需要耐心，做B2需要果断，做B3需要反应快
18. 没有出现B2的B1可能是假B1
19. 没有出现B3确认的B2可能失败
20. 三件套凑齐后走势流畅概率大大提高

## 七、失败场景

1. B1之后一直不出现B2，持续新低
2. B2出现后第二天是阴包阳
3. B3没有出现，股价跌破B2低点
4. B2的勾大于55，上涨空间有限
5. B2涨幅不足4%，力度不够
6. B2没有放量，可能是假突破
7. 横盘期间出现绿肥红瘦
8. 高位放量滞涨
9. 跌破白线后没有收回
10. 打到黄线后继续跌破
