## 核心知识点

### 1. 双线定义

| 线条 | 名称 | 含义 |
|------|------|------|
| 白线 | 短期趋势线 / 牵牛绳 | 衡量短期波段的流畅度及强弱，跌破意味着短期趋势结束 |
| 黄线 | 大哥线 / 多空线 / 主力成本线 | 主力控盘成本价，一般不会有效跌破，是极限支撑位 |

### 2. 核心玩法

| 信号 | 含义 | 操作 |
|------|------|------|
| 白线金叉黄线 | 上涨趋势确立 | 战略入场点 |
| 白线死叉黄线 | 趋势破坏 | 最后离场时机，无论盈亏都要走 |
| 白线与黄线区间 | 容错率较高的买入区 | 只要N型结构不破，区间内任何位置都可分批建仓 |
| 放量金叉后缩量回踩黄线 | 震仓点 / 主升启动点 | 交易价值非常大，往往是连续拉升前的最后震仓 |

### 3. 只做白线在黄线上

- **黄线之下直接不看** - 没有交易价值
- **白线在黄线之上** - 多头趋势，可以操作
- **白线在黄线之下** - 空头趋势，不操作

## 规则提取

### 买入时机

| 规则 | 触发条件 | 具体动作 |
|------|----------|----------|
| 规则1 | 白线金叉黄线后 | 等回踩，在白线与黄线之间入场 |
| 规则2 | 金叉后 | 一直拿到死叉，可以吃满整个波段 |
| 规则3 | N型上涨趋势中 | 白线与黄线区间内随便买，容错率高 |
| 规则4 | 缩量回踩黄线 + J值大负值 | 极限买点，往往是主升浪启动前震仓点 |
| 规则5 | 放量金叉后缩量回踩 | 交易价值极大，是连续拉升前的最后震仓动作 |
| 规则6 | 死叉而未死叉 + N型不破 + J值大负值 | 极限买点 |
| 规则7 | 区间内 | 分批建仓，每天买一点降低成本 |
| 规则8 | 突破区间后回踩 | 股价放量突破横盘区间后回踩，在白线与黄线之间是较好买点 |
| 规则9 | 长期横盘后放量站上 | 长期横盘后放量站上白线，同时白线在黄线之上，是强势信号 |

### 止损纪律

| 规则 | 触发条件 | 具体动作 |
|------|----------|----------|
| 规则1 | 跌破白线 | 全清 - 白线是短期趋势线，跌破意味着短期趋势结束 |
| 规则2 | 白线死叉黄线 | 最后离场时机，走错也要走 |
| 规则3 | 跌破黄线未收回 | 第二天无法拉回，需考虑止损 |
| 规则4 | 高位出现出货形态 | 放量大长阴、阶梯量、高位放量滞涨等，必须走 |
| 规则5 | N型结构被破坏 | 低点开始降低，无论是否死叉都需退出 |
| 规则6 | 放飞后跌破成本 | 剩余仓位跌破成本价或微利位必须清 |
| 规则7 | 下跌趋势中 | 白线在黄线下方，任何反弹都是逃命机会，不做 |
| 规则8 | 单票达到持仓上限后回到区间 | 只卖不买，不能再加仓 |

### 出货形态（5种）

1. 连续加速上涨后放量大长阴
2. 阶梯量（成交量逐级放大）
3. 高位放量滞涨（量价背离）
4. 顶部连续大阳线后快速回落
5. 高位连续放量但股价不涨

### 目标位设置

| 情况 | 动作 |
|------|------|
| 出现第一种出货形态 | 减仓1/3 |
| 出现第二种出货形态 | 减仓1/2 |
| 出现第三种出货形态 | 清仓 |
| 股价远离白线5%以上 | 考虑分批放飞 |
| 白线死叉黄线 | 全部清仓 |

## 识别步骤（10步）

1. **判断大势** - 打开股票首先看股价在黄线之上还是之下，黄线之下直接不看
2. **确认趋势方向** - 白线在黄线之上表示多头趋势，可以操作
3. **等待金叉信号** - 白线金叉黄线时，上涨趋势确立概率大
4. **找买入区间** - 金叉后等待回踩，在白线与黄线之间的任何位置都可以分批建仓
5. **判断是否在区间内** - 只要股价在白线和黄线之间运行，就是安全区间
6. **等待震仓点** - 放量金叉后缩量回踩黄线，这是主升浪启动前的最后震仓点
7. **结合KDJ指标** - 当J值打到较大负值（如负10以下）时，是较好的买入信号
8. **识别出货信号** - 出现大长阴、阶梯量、放量滞涨等五种出货形态时，要考虑减仓
9. **等待死叉信号** - 白线死叉黄线是最后离场时机
10. **严格执行纪律** - 跌破白线要走、跌破黄线要走、死叉要走

## 关键原则（16条）

1. 双线是二维系统 - 白线是一维、KDJ是一维，加黄线变成三维
2. 白线金叉黄线 = 赌场开门 - 意味着主力入场
3. 白线死叉黄线 = 赌场关门 - 意味着主力弃盘，必须走
4. 白线是牵牛绳 - 跌破意味着短期趋势结束
5. 黄线是成本线 - 是主力控盘成本价，是极限支撑位
6. 区间内随便买 - N型上涨趋势中容错率很高
7. 不要追求精确买点 - 区间内买错了也能涨回来
8. 震仓点是送钱 - 放量金叉后缩量回踩黄线交易价值非常大
9. J值配合使用 - J值打到大负值是辅助买入信号
10. 出货形态必须走 - 五种出货形态出现时，无论盈亏都要考虑离场
11. 大票更有效 - 成交额大的股票主力画不了线
12. 只做白线在黄线上 - 黄线之下没有交易价值
13. 拿住才能赚大钱 - 不要因为短期波动频繁交易
14. 分批建仓分批卖 - 不要一把梭哈
15. 循环操作 - 趋势不破就反复在区间内买
16. 看图要找依据 - 任何买卖都要有依据

## 失败场景

1. 震荡行情反复打脸 - 横盘区间内白线和黄线反复交叉
2. 假突破后回落 - 放量突破后快速回落形成假突破
3. 小票画线 - 小市值股票主力可以随意画线
4. 基本面倒转 - 公司业绩暴雷技术分析失效
5. 极端行情 - 突发利空导致暴跌
6. 拿不住卖飞 - 小幅盈利就跑了
7. 不止损深套 - 不舍得住止损越套越深
8. 频繁交易 - 手续费吃掉了利润
9. 盲目追热点 - 只看热点不看双线位置
10. 不懂不做 - 做自己看不懂的图形

## 注意点

1. 双线战法适用于有流动性的股票 - 成交额太小的股票不适用
2. 港股不适用 - 港股流动性差
3. 横盘期间切换方法 - 震荡时不能用双线
4. 不要用后复权 - 要用前复权或者不复权
5. 周线级别更稳定 - 可以参考周线的双线信号
6. 量在价先 - 成交量是先行指标
7. 形态配合使用 - 双线配合N型结构、成交量、K线形态
8. 仓位管理 - 不要把所有钱买一只票
9. 复盘总结 - 定期复盘交易
10. 知行合一 - 制定了规则就要严格执行
11. 心态要好 - 不要因为短期波动影响心态
12. 市场在变 - 要不断学习新技术新方法

## 总结

双线战法是一套完整的**右侧交易系统**，核心逻辑：

- **趋势判断**：白线在黄线之上 = 多头趋势，可以操作
- **买入策略**：金叉后等回踩，在白线与黄线区间内分批建仓
- **卖出纪律**：死叉是最后离场时机，必须执行
- **核心优势**：N型结构中的白黄区间是容错率较高的买入区
- **配合指标**：KDJ的J值大负值是辅助买入信号

**适用场景**：单边上涨趋势行情
**不适用场景**：横盘震荡、下跌趋势、港股、小市值股票
