## 一、当前市场判断（2026年初）

### 核心特征
- **龙队主导的慢牛节奏**：市场呈现"上有顶，下有底"的箱体震荡格局
- **双宽政策周期**：货币宽松 + 信用宽松，政策面持续呵护
- **估值偏高区域**：主线科技股估值普遍偏高，需等待基本面数据验证
- **外部风险长期化**：中美对抗预计持续20-50年，美股科技股存在高估值回调风险

### 牛市进度判断
- 924行情至今1600余只个股翻倍，仍有3400余只未到翻倍
- **牛市标准**：全市场50%个股翻倍后再翻倍，10%个股翻5-10倍
- **时间窗口预估**：快则2027年，慢则2029年

### 环境判断关键指标

| 指标 | 阈值 | 含义 |
|------|------|------|
| 活跃市值单日跌幅 | >-2.3% | 执行"只卖不买" |
| 百点长阴 | 单日显著跌幅 | 暴力洗盘，可能是机会 |
| 缩量后倍量柱 | 量是前一次2倍+ | 底部信号 |
| 放量后缩量 | 高位连续 | 顶部信号 |

## 二、核心策略：底仓+动态仓双轨配置

### 策略框架

```
总仓位 = 底仓（70%-80%）+ 动态仓（20%-30%）
```

### 底仓（70%-80%）

**选择三重标准：**
1. **估值足够低**：白酒、煤炭、银行等传统行业处于历史低位
2. **未来确定性强**：行业龙头地位稳固，技术/市场壁垒高
3. **龙队主仓品种**：机构重仓但短期回调的品种

**底仓配置示例：**
- 券商（20%）
- 白酒（10%）
- 煤炭（10%）
- 低波红利（10%）
- 队长（10%）

**底仓原则：配置后不频繁操作**

### 动态仓（20%-30%）

**操作依据（按优先级）：**
1. 活跃市值择时信号（B1/B2/B3形态）
2. 单针探底形态
3. 突破走势信号
4. 量比指标异动

## 三、平台交易法（2.4升级战法）

**核心逻辑：**
```
筑平台 → 升平台 → 有效跌破黄线支撑 = 行情结束
```

**实战口诀：**
> "上有顶下有底，开始筑平台"

**操作要点：**
- 关注黄线支撑位，未有效跌破则保持乐观
- 价格企稳后会经历"震荡→横盘"过程
- 典型走势：平→震荡→站平台→升平台循环

## 四、买入/卖出条件

### 买入条件

**底部确认信号：**
- 连续缩量后出现**倍量柱**（成交量为前一次2倍以上）
- 周线呈现**低点抬高**形态（N型上涨结构）
- 出现明显异动信号（量比突增、大单买入）

**最佳买入时机：**
- 百点长阴后的反弹机会（"暴跌是机会"）
- 突破平台后的回踩确认
- 底仓成本区附近（主力建仓密集区）

### 卖出/只卖不买条件

**顶部信号：**
- 倍量柱出现后首次放量形成波段高点
- 出现"阶梯量出货"或"次高点出货"

**只卖不买触发：**
- 活跃市值出现 **-2.3%以上** 单日跌幅时，执行"只卖不买"
- 逐步减仓至30%底仓，不一次性清仓（避免错过反弹）

## 五、仓位管理规则

### 按资金体量分仓

| 资金体量 | 分仓数量 | 备注 |
|----------|----------|------|
| 2万 | 1只 | 集中风险 |
| 5万 | 2仓 | 开始分散 |
| 10万 | 2-3仓 | 关键转折点 |
| 20万 | 4仓 | 波动率显著降低 |
| 100万 | 5-8仓 | 需完整配置体系 |

### 动态仓位调整原则
- 科技主线保持60%，40%配置防御性板块
- 科技板块出现5%以上回调时，可增加10%防御仓位
- 暴跌时保留底仓（50%/30%/0%分级）

### 交易频率控制（重要）
- **建议每月开仓4次**（约每周1次）
- 目的：戒除赌徒心理，减少无效交易
- 连续3次亏损 → 强制空仓，重置节奏

## 六、风险控制规则

### 硬性纪律

| 规则 | 说明 |
|------|------|
| 禁止融资加杠杆 | 避免"一波带走" |
| 连败3次 → 强制空仓 | 打破负向循环 |
| 获利40% → 提取一半利润 | 保护本金安全 |
| 死叉出现 → 警惕 | 白线下穿黄线意味着筹码被套 |

### 风险关键数据

| 风险指标 | 阈值 | 措施 |
|----------|------|------|
| 单日跌幅 | -2.3% | 只卖不买 |
| 最大回撤 | 25% | 预警 |
| 连续亏损 | 3次 | 强制空仓 |
| 科技股回调 | 5% | 增加防御仓 |

## 七、量价关系升级法则

### 底部判断（倍量柱规律）
- 连续缩量后出现倍量柱 → **必是阶段性底部**
- 双倍量柱可能形成双底结构
- 缩量→倍量→放量循环 = 判断波段标准模式

### 顶部判断
- 倍量柱出现后首次放量 → **必形成波段高点**
- 放量后价格立即回落 = 出货信号

### 安全操作区间
- 量价齐升阶段 = 最安全操作区

## 八、板块轮动规则

- **主线不变**：科技 + 有色 + 电力，不存在"高低切"
- **调整期**：资金转入防御板块（银行/煤炭）
- **轮动信号**：从计算机、半导体、传媒、通信 向 低位板块切换
