# 九篇心法精讲 - 核心要点整理

## 第一篇：太过完美而不敢买入

### 核心观点
**心理障碍**：因之前按同样方法亏损，导致不敢买入"完美图形"的牛股。

### 散户典型心理
- 感觉过于完美，像是骗线
- 之前按此图形买过，亏了
- 担心假突破，日内亏损大

### 应对策略
1. **坚决买入，严格止损**
2. 分批下单，控制日内成本
3. 严格观察第二日情况
4. 买入当日出现3/4量阴线 → 次日开盘走

### 实战规则
- 上升波段：仓位10%
- 震荡波段：仓位5%
- 下跌波段：仓位2-3%
- 核心：不要想太多，坚持干

## 第二篇：忽视热点切换的苗头

### 核心观点
**心理障碍**：对某股票有负面印象（消息乱、套牢多），忽视其技术买点。

### 散户典型心理
- 潜意识觉得被主力玩坏了
- 感觉上方套牢筹码多
- 当时热点不在这个板块

### 应对策略
1. 忽略筹码理论和资金进出分析
2. 只从关键位置大资金回流角度考虑
3. 思考方式简单点，错了用3/4量阴线止损
4. 克服偏见，第一时间打起精神

### 实战规则
- 无穷成本线附近是重点关注位置
- 跳空高开超过2%要等回落再买
- 克服心理偏见，不留遗憾

---

## 第三篇：日内假反转

### 核心观点
**心理障碍**：主力出货后快速拉起，担心是假突破不敢买。

### 散户典型心理
- 主力放量出货后，觉得顶部已见
- 斜率太高，不敢追
- 担心大盘股连续拉升见顶

### 应对策略
1. 树立盈亏比概念
2. 下跌风险清晰可见，上涨空间值得期待
3. 在8日成本线附近买入，损失不会太大
4. 买入后做好3/4量阴线止损

### 实战规则
- 大盘龙头股跌破8日成本线 = 出货信号
- 只做8日和60日成本均线的企稳
- 利润空间：1根大阳线利润

## 第四篇：上次失败直接影响下次

### 核心观点
**心理障碍**：在同一只股票上连续犯错误，被"戏耍"后产生抗拒心理。

### 散户典型心理
- 第一次买入大跌，心理有阴影
- 被主力戏耍后主观认输
- 连续出现买点时依然忽视

### 应对策略
1. 先问三个问题：大盘适不适合做？这票题材好不好？技术图形是否完美？
2. 第一次买点错误造成亏损后，不要影响后续操作
3. 完美图形就得干，注意止损
4. 第三次假突破后放量阴线（特殊K线）必须先出来

### 实战规则
- 节奏很重要
- 不要因为前期亏损影响后续判断
- 每个买点独立判断

## 第五篇：看别人抄底成功自己也要试

### 核心观点
**心理障碍**：看到别人抄底成功，自己也想尝试，盲目抄底。

### 散户典型心理
- 看到牛股洗盘到均线企稳回升
- 想体验"快感"，盲目抄底
- 逐渐加仓，陷入泥潭

### 应对策略
1. 明确自己的交易策略
2. 没有抄底策略就不要尝试
3. 抄底需要严格策略保障
4. 不要盲目抄底，要有依据

### 实战规则
- 基金抄底危险很大
- 遇到股灾，会死很惨
- 只有一种抄底策略：有大资金回流迹象的企稳阳线

## 第六篇：以个人持股成本对待市场转势

### 核心观点
**心理障碍**：以自己买入成本来期待股票上涨，忽视市场转势信号。

### 散户典型心理
- 买入后希望马上大涨
- 不愿接受洗盘
- 以成本价索求期望利润空间

### 应对策略
1. 站在主力/获利盘角度思考
2. 大阳线后进入要特别注意盘中卖点
3. 出现转势信号第二天一定要走
4. 拉高要减仓，踏空概率小

### 实战规则
- 建仓当天出现反转 → 第二天砍仓
- 坐享第二根大阳线 → 出现卖点减仓或清仓
- 持续看好 → 低位再接回

## 第七篇：当你觉得舒服的时候，恰恰是风险最大时刻

### 核心观点
**心理障碍**：感到舒服=放松警惕=风险来临。

### 散户典型心理
- 上午全盘皆红 → 感到舒服
- 下午突然变盘 → 得而复失
- 卖完又拉回去 → 郁闷，再买又被套

### 应对策略
1. 市场一切目的都是折腾你
2. 千万不要让自己感到舒服
3. 觉得自己了解市场 = 危险信号
4. 感到舒服时 → 注意转折点
5. 不得贪胜，见好就收

### 实战规则
- 记住：不确定性、随机性
- A股大小非肯定赚钱
- 连世界最赚钱的指数投资都难赚钱
- 舒服时格外注意转折点

## 第八篇：劣仓驱逐良仓

### 核心观点
**心理障碍**：恐慌时卖出的是好股票，留下的是烂股票。

### 散户典型心理
- 大盘不稳定 → 产生持仓恐惧
- 恐慌时优先卖出浮盈的强势股
- 主观期盼反弹，不愿砍走坏的票

### 应对策略
1. 首先遵守信号：是否出现3/4量阴线？砖型图是否翻绿？
2. 没有走坏 → 踏踏实实拿着
3. 持有期间大幅拉升 → 减仓
4. 主动减仓后，主动权在自己手里

### 实战规则
- 两个关键动作：
  - 日内拉高减仓
  - 遵守日线离场信号
- 走坏的票不砍 = 最大潜在亏损风险

## 第九篇：反制反心理特征的研究

### 核心观点
**核心思维**：交易是艺术，不是科学。交易本质是对不确定性的实验。

### 散户典型心理
- 追求"确定性机会"
- 恐惧不确定性
- 恐惧导致动作变形

### 应对策略
1. **树立不确定性思维**：买进去后看看会发生什么
2. **买入后观察**：是否出现3/4量阴线？
   - 出现 → 次日冲高走人
   - 没出现 → 继续持有
3. **持有期间**：放量后观察次日是否3/4量阴线
4. **加速冲高**：可减仓或等次日信号
5. **物来则应，过去不留**

### 交易策略框架

| 动作 | 策略 |
|------|------|
| 买入 | 进去后看发生什么 |
| 持有 | 等收盘价确认走势 |
| 卖出 | 3/4量阴线 / 放量阴线减仓 |

### 核心铁律
- 49%与51%概率没区别
- 科学从未战胜市场
- 不确定性是本质
- 知易行难，且行且犯错，犯错请改正
