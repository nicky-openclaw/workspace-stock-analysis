# 主力出货五种方式

> 来源：2024年9月17日直播课程
> 系列：9.17主力出货五种方式

---

## 核心定义

**主力出货**是指个股在上涨过程中，主力资金通过特定技术图形和量价关系，将持仓筹码在高位派发给散户的过程。识别主力出货对于保护利润至关重要。

**核心观点**：
- 顶部只有一个，背离可以有无数个
- 量价位置关系是判断出货的核心
- 加速是出货的前提，没加速的放量可能是试盘
- 主力出货是一个过程，不会当天出完

---

## 五种出货方式详细定义

### S1：加速后单日放天量大阴线

**定义**：个股经过连续上涨加速后，出现单日放天量的大阴线，成交量创出近期天量，股价高位放量大阴线后后续持续下跌或做双头。

**识别特征**：
1. 前期必须有明显的加速上涨阶段（连续大阳线或涨停）
2. 大阴线当天成交量创出近期天量（通常为均量的数倍）
3. 大阴线当天跌幅要足够大（通常5%以上）
4. 出现在加速阶段之后，不是横盘或调整阶段

**教学案例**：中财科技（8月19日）、中国中铁（2014年12月22日）、镇洋发展（2024年9月3日）、稳健医疗

---

### S2：加速后次高点突然巨量长阴

**定义**：在前一日最高点时成交量相对缩量或正常，下一交易日突然出现巨量跌停或巨量长阴线，不是在最高点当天出货，而是次高点突然反转。

**识别特征**：
1. 前一日最高点成交量相对缩量或正常
2. 下一交易日突然出现巨量跌停或巨量长阴线
3. 伴随着资金链断裂、利空消息或主力决定放弃
4. 往往出现在反弹无力的次高点位置

**教学案例**：民生银行（2013年2月7日）、东方财富（2020年7月16日）、宁德时代（2021年12月7日）、金溢科技

---

### S3：连续阶梯放量下跌

**定义**：创新高后连续出现放量下跌，每根阴线成交量比前面阳量更大，是A股独有的博弈思路。

**识别特征**：
1. 股价创出阶段性新高后开始下跌
2. 连续出现放量下跌，阴线成交量递增
3. 每根阴线成交量比前面阳量更大
4. 形态非常难看，呈阶梯状

**教学案例**：光线传媒（2025年2月17日）、万科A（2018年1月29日）、宁德时代、民生银行（2025年）

---

### S4：双头双放量巨阴

**定义**：中盘股常见，形成双头形态，两个头部都出现放量巨阴，出货需要多次反复。

**识别特征**：
1. 形成明显的M头或双头形态
2. 两次头部位置都出现放量巨阴
3. 盘子越大，出货方式越综合
4. 第二个头是最后的逃命机会

**教学案例**：卫宁健康（2025年2月17日-3月10日）、正阳发展

---

### S5：顶部绿长红短（绿肥红瘦）

**定义**：顶部没有突然出现放量巨阴也不会突然暴跌，主力性格温和慢慢出货，整个顶部区域呈现绿肥红瘦形态。

**识别特征**：
1. 顶部没有突然出现放量巨阴
2. 也不会突然暴跌出现巨阴
3. 整个顶部区域呈现绿肥红瘦形态
4. 下跌时绿柱长，上涨时红柱短

**教学案例**：华谊兄弟（2013年）、中国中铁（2014年12月）、中煤能源

## 核心原则

### 判断原则

1. **加速是前提**：没有加速的放量可能是试盘，不是出货
2. **量价为核心**：重点看量价位置关系，不要依赖MACD、KDJ等指标
3. **顶部唯一性**：顶部只有一个，背离可以有无数个
4. **尾盘确认**：出货信号必须等尾盘确认，盘中波动大不要过早操作
5. **宁可信其有**：宁可卖飞不要被套

### 操作原则

1. S1信号出现当天，必须至少减仓一半或全部卖出
2. S2信号出现当天，必须立即减仓或清仓
3. 次日如果低开或下跌，继续减仓不要犹豫
4. 不要试图等到反弹再卖，次日往往还有更低点
5. 双头形态的第二个头是最后逃命机会
6. 跌破白线（短期趋势线）必须止损
7. 跌破黄线（中期趋势线）必须止损

### 盘口特征

1. 白线都不要了，黄线也不要了，说明主力真走了
2. 高位区域所有阳量都在缩小，说明买盘枯竭
3. 绿肥红瘦（绿柱长红柱短）是顶部常见形态
4. 连续阶梯放量下跌是最丑的出货形态

## 失败场景

| 场景 | 描述 | 教训 |
|------|------|------|
| 场景1 | 把洗盘当成出货 | 横盘调整中的放量长上影不是出货（没加速） |
| 场景2 | 过早卖出 | S1出现后次日反包，继续持有 |
| 场景3 | 抄底失败 | 大阴线后次日低开抄底，结果还有更低点 |
| 场景4 | 被双头诱惑 | 以为还有行情，结果第二头是最后的卖点 |
| 场景5 | 迷信换手率 | 以为低换手率不会出货，实际大盘股低换手也能出货 |
| 场景6 | 看技术指标出货 | 顶部反复背离，按照背离信号会被反复打脸 |
| 场景7 | 股价刚启动时误判 | 误以为主力出货，过早卖出错过主升浪 |
| 场景8 | 假阴真阳误判 | 盲目认为是调整，实际是主力出货信号 |
| 场景9 | 牛市环境误判 | 大牛市中误判出货信号，结果卖飞大牛股 |

## 关键概念

| 概念 | 含义 |
|------|------|
| 白线 | 短期均线（5日），持仓成本线，牵牛绳 |
| 黄线 | 中期均线（20日），关键支撑位 |
| 天量天价 | 成交量创近期最大，对应最高价 |
| 假阴真阳 | 收盘价高于开盘价但低于前一天收盘价的K线 |
| 绿肥红瘦 | 绿柱长红柱短，顶部的卖出信号 |
| 阶梯量 | 连续放量下跌，每根阴线量能递增 |
| B1信号 | 砖型图选股信号，放量站上黄线后的买入信号 |
