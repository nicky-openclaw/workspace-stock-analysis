## 核心交易规则

### 买入时机

| 规则 | 说明 |
|------|------|
| 超短买入 | 集合竞价买入，开盘30秒内决定是否成交 |
| 超短信号 | KDJ勾起大负值（J值打到13以下） |
| 强势股回调 | 白线在黄线之上，股价回调到黄线位置买入 |
| 突破买入 | 突破关键压力位后买入 |
| B1信号 | 低位转折点买入 |
| B2突破 | 突破平台后买入 |
| 多头区间 | 等活跃市值转为多头区间时考虑买入 |
| 确定性机会 | 等确定性机会再动手 |

### 止损规则

| 规则 | 说明 |
|------|------|
| 超短止损 | 9点33或9点37跌破黄线立即止损 |
| 跌破黄线 | 必须走，最多等一根确认 |
| 跌破白线 | 无条件止损 |
| 亏损限度 | 亏损3%-5%必须止损 |
| 超短纪律 | 做超短第二天不涨就止损 |
| 波段止损 | 波段跌破黄线走人 |
| 破位处理 | 破位股票必须走 |

### 目标位设定

| 规则 | 说明 |
|------|------|
| 超短目标 | 一根K线盈利即可走人 |
| 波段目标 | 上涨趋势中用白线牵牛绳，只要白线不破就持有 |
| 2026年目标 | 把钱揣兜里，保住本金为主 |

## 关键原则

1. **活跃市值空头区间只卖不买或极小仓位**
2. **超短就是超短，不要扛单，超短只赚一根**
3. **9点33和9点37是两个关键时间点**
4. **白线在黄线之上是多头控盘，可以持有**
5. **白线在黄线之下是空头区间，不要持有**
6. **跌破黄线就是破了，不要找理由**
7. **不要与盘面杠，要顺势而为**
8. **做滑头不做死多头或死空头**
9. **去弱留强，永远选择最强的股票**
10. **不要追涨幅超过5%的股票**
11. **尾盘买股被套是活该**
12. **周线决定方向，日线决定买卖点**
13. **看长做短，用周线指导方向**
14. **止损是舍小钱保大钱**
15. **2026年很难，要把钱揣兜里**

---

## 失败场景

- 在空头区间重仓买入
- 超短不止损，短线做成长线
- 追涨破位的股票
- 在活跃市值空头区间持有不动
- 满仓轮单个股票遭遇连续跌停
- 不止损被深套
- 抄底：白线在黄线之下还买入
- 死多头：不看技术面一直持有
- 抱有幻想：觉得会涨回来

- 动态仓做的手紧一点
- 底仓加动态仓模式
- 跌破黄线两天以上基本确认下跌趋势
- 强势股才能抗跌
- 做超短要快进快出
- 日线破位看周线，周线破位看月线
- 新手入市要慢慢学，不要急于赚钱
