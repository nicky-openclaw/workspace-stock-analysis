# 交易体系总知识库

> 本知识库整合自12期直播课程，构建完整的量化+技术分析交易体系。
> Agent调用时：先走骨架判断，再按模式切换细分规则。

---

## 第一层：骨架判断（任何模式都必须通过）

### 1.1 趋势判断（双线战法）

**核心规则**：
- 白线（5日均线/BBI）：短期趋势线，流畅波段的牵牛绳
- 黄线（20日均线/多空线大哥线）：主力成本线，极限洗盘位
- **基础条件**：白线必须在黄线之上，否则不做

**判断标准**：
| 信号 | 含义 | 操作 |
|------|------|------|
| 白线金叉黄线 | 上涨趋势确立 | 等B1回踩入场 |
| 白线死叉黄线 | 中期趋势结束 | 走错也要走 |
| 放量金叉后缩量回踩黄线 | 交易价值非常大 | 最佳入场点 |
| 跌破白线 | 短期趋势损坏 | 止损 |

### 1.2 量能验证（量价关系）

**核心规则**：
- 放量只在**上涨过程中**才有意义
- 下跌时无论放量缩量都视为真实下跌

**量价信号表**：

| 形态 | 量能特征 | 价格特征 | 含义 | 操作建议 |
|------|----------|----------|------|----------|
| **倍量** | 成交量≥前日2倍 | 中长阳 | 增量资金入场 | 重点关注，等回调B1 |
| **天量** | 倍量后再倍量 | 高位 | 加速尾声 | 警惕，开始放飞 |
| **地量** | 回调阶段最小量 | 红线位置 | 回调底部 | 地量+B1=最佳买点 |
| **缩量回调** | 成交量缩小 | 小幅回调 | 洗盘，趋势未结束 | 继续持有 |
| **缩量上涨** | 成交量减少 | 价格上涨 | 不真实 | 慎重观察 |
| **量价齐升** | 逐步放大 | 创新高 | 真实买入 | 确认后可入场 |

### 1.3 主力证据（关键K + 暴力K + 倍量柱）

**关键K类型**：
1. **底部平地惊雷**：横盘转上涨，放量涨停
2. **紧急刹车**：下跌转横盘
3. **顶部关键K（S1）**：高位放量阴线
4. **向下趋势反转**：关键位置放量大阴线
5. **区域突破**：突破前期高点的放量大阳线

**暴力K类型**：
1. **趋势扭转型**：长期下跌末端，改变下跌趋势
2. **趋势改变型**：下跌后横盘相对底部
3. **趋势延续型**：上涨趋势中回调低位（B1位置）

**三位一体信号**：
- 倍量柱：增量资金明确入场
- 关键K：重要支撑位
- 暴力K：主力强度

### 1.4 止损铁律（通用）

| 层级 | 止损规则 | 适用场景 |
|------|----------|----------|
| **K线止损** | 买入当根K线最低价下方3-5个价位 | 任何新开仓 |
| **白线止损** | 收盘跌破白线 | 短线持仓 |
| **黄线止损** | 收盘跌破黄线 | 中线持仓 |
| **N型止损** | 跌破N型结构前低 | 趋势破位 |
| **S1止损** | 高位放量上影线 | 顶部信号 |
| **盈转亏止损** | 由盈利变亏损 | 铁律 |

## 第二层：择时（进场时机）

### 2.1 宏观择时（五步工作流·步骤1）

**活跃市值判断**：
| 信号 | 阈值 | 市场性质 | 策略 |
|------|------|----------|------|
| 多头信号 | 活跃市值 ≥ 4% | 晴天/做多 | 玩松，满仓/重仓 |
| 空头信号 | 活跃市值 < -2.3% | 阴天/做空 | 玩紧，轻仓/空仓 |

**执行流程**：
1. 每天开盘前看活跃市值
2. ≥4%：开启做多模式，可用B1/B2/B3/补票
3. <-2.3%：进入防守模式，仅做B1，轻仓

### 2.2 对称择时（独门对称战法·时间对称）

**时间对称应用**：
- 上升周期对应下降周期（康波周期）
- 当前处于从衰退向复苏周期走的转折点
- 对称完美后需要新的外力才能继续趋势

**空间对称（独门对称战法）**：
- **直接对称**：A股杀，左边涨右边直接跌回去，A杀下来的票不要碰
- **间接对称**：A股起来后回调只回一半，被多头力量顶上去，最佳入场信号
- **斜率改变**：斜率发生明显改变意味着多空力量失衡

**形态对称（独门对称战法）**：
- **轴对称**：以一条水平线为轴，左右两边形态对称，适合做突破行情
- **中心对称**：以一个中心点为中心旋转对称，出现在横盘整理区间

**守恒被破坏核心**：
- 只在守恒被破坏的位置才有交易价值
- 走势必对称，但要找不完美的走势
- 走横是最有价值的买入点
- 守恒被破坏标志：原本应该下跌却走横/上涨、斜率明显改变、横盘后突破K线

**B1买入三条件**：
1. 守恒被破坏
2. 走横
3. KDJ的J值勾起大负值（13%以下）

## 第三层：标的筛选（选哪只票）

### 3.1 筛选优先级

**从高到低筛选逻辑**：
1. **趋势优先**：周线级别白线在黄线之上，n型上涨结构
2. **资金证据**：关键K + 暴力K + 倍量柱三要素
3. **形态配合**：走横（间接对称）> 直接对称
4. **位置确认**：回调到白线/黄线附近

### 3.2 关键K筛选
- 放量是关键K最核心的识别条件
- 300亿以上盘子关键K更准
- 必须在关键位置（大哥线/均线附近）

### 3.3 暴力K + 倍量柱筛选
- 倍量：成交量是前一交易日2倍及以上
- 暴力K：突兀、莫名其妙的大阳线
- 三门重炮：连续三根倍量，建仓充分

### 3.4 击穿对手盘机会识别
- **前提**：前期必须有倍量柱+关键K+暴力K组合
- **特征**：缩量击穿（长阴短柱），而非放量斩杀
- **信号**：地量出现 = 抛压清洗干净

### 3.5 对称位置识别
- **间接对称**：回调只走一半然后走横，最佳入场信号
- **直接对称**：A杀下来的票不要碰
- **守恒破坏**：应该下跌却走横/反弹的位置

## 第四层：买卖点（精准进出）

### 4.1 B1/B2/B3买点体系

| 买点 | 定义 | 盈亏比 | 止损位置 | 适用环境 |
|------|------|--------|----------|----------|
| **B1** | 压抑拐点/底部第一根 | 最高 | 买入K线最低价 | 任何环境 |
| **B2** | B1之后的再次启动 | 中等 | B2那根K线低点 | 多头/松 |
| **B3** | 对称位置二次启动 | 较低 | 视情况 | 多头/松 |

**B1识别条件**：
- 白线在黄线之上
- 出现关键K异动
- 缩量下跌打到碗里（黄线附近）
- KDJ勾大负值（13%以下）

**B2识别条件**：
- B1之后的再次启动
- 涨幅大于4%
- 放量，被量柱确认
- 平行重炮/灾后重建/跃跃欲试形态

### 4.2 三件套完整确认
1. **双线确认**：白线在黄线之上
2. **量价确认**：倍量+中长阳，或地量+B1
3. **形态确认**：关键K/暴力K/走横信号

### 4.3 量价买入信号组合
| 组合 | 含义 | 确定性 |
|------|------|----------|
| 地量 + B1 | 最佳买点 | 最高 |
| 倍量 + 中长阳 | 大哥来了 | 高 |
| 三门重炮 | 建仓充分 | 高 |
| 缩量回调 + B1 | 趋势未结束 | 中 |

### 4.4 卖出信号体系（S1等）

| 信号 | 特征 | 操作 |
|------|------|------|
| **S1** | 高位放量上影线/大阴线 | 至少卖一半 |
| **放飞** | 冲高3.5%-4%以上中长阳 | 分批卖出 |
| **滴滴** | 收盘跌破白线 | 卖出 |
| **天量** | 倍量后再倍量 | 警惕，开始放飞 |
| **量价背离** | 创新高但缩量 | 谨慎，警惕见顶 |

## 细分交易模式

### 模式A：波段中线

**适用场景**：多头市场 + 有一定资金 + 周线选股

**操作流程**：
1. **周线筛选**：白线在黄线之上，n型结构，暴力K/倍量柱
2. **日线等B1**：回调到白线/黄线附近出现B1
3. **分批建仓**：碗区内分批买
4. **持仓待涨**：白线之上持有
5. **放飞卖出**：加速后放飞，或出现S1

**仓位建议**：
- 4-10只票分散
- 单票20-25%

### 模式B：超短线

**适用场景**：任何市场 + 小资金（10万以下）

**操作流程**：
1. **砖形图选股**：绿转红，红柱≥绿柱2/3
2. **双线确认**：股价在黄线之上，白线在黄线之上
3. **尾盘/次日早盘买入**：高开4%以上不追
4. **2根K线原则**：没有爆发力就走
5. **止损**：买入K线最低价

**执行口诀**：
- 我要赚钱（积少成多）
- 不给就走（不犹豫）
- 永不完美（踏空是策略）
- 下一个会更好

### 模式C：击穿后布局

**适用场景**：有主力建仓证据 + 当前处于洗盘阶段

**操作流程**：
1. **确认前期异动**：倍量柱+关键K+暴力K
2. **识别击穿形态**：缩量下跌（长阴短柱）
3. **等待地量信号**：抛压清洗干净
4. **右侧入场**：地量后企稳买入
5. **止损设置**：关键K最低价

### 模式D：五步工作流日常执行

**适用场景**：通用，每天12分钟

**执行流程**：

| 步骤 | 内容 | 耗时 |
|------|------|------|
| 1. 择时 | 看活跃市值，判断多空 | 1分钟 |
| 2. 定策略 | 玩松/玩紧，确定战法组合 | 2分钟 |
| 3. 复盘 | 预设明天操作指令 | 3分钟 |
| 4. 选股 | 筛选候选票 | 5分钟 |
| 5. 执行 | 开盘/收盘前执行 | 1-2秒 |

## Agent决策树

### 分析某只票是否值得做

```
白线在黄线之上？
  → 否：不做，观望
  ↓ 是
有关键K/暴力K/倍量柱？
  → 否：观察不操作
  ↓ 是
当前位置？
  → 击穿阶段：等地量B1
  → 上涨中继：找B3
  → 回调中：找B1
  ↓
量能配合？
  → 地量/缩量回调 → B1入场信号确认
  → 放量滞涨 → 等待或放弃
  ↓
执行买入，止损设好
```

### 今日选股流程（五步简化版）

```
1. 开盘前：活跃市值 ≥ 4%？→ 是：做多 / 否：防守
2. 筛选：白线在黄线之上 + 关键K/暴力K/倍量柱
3. 等信号：B1 / B2 / 对称走横
4. 入场：尾盘或次日早盘
5. 止损：K线最低价 / 白线 / 黄线
```

| 层级 | 条件 | 止损位 |
|------|------|--------|
| 1 | 新开仓 | 买入K线最低价 |
| 2 | 短线持仓 | 跌破白线 |
| 3 | 中线持仓 | 跌破黄线 |
| 4 | 趋势破位 | 跌破N型前低 |
| 5 | 顶部信号 | 出现S1 |

## 关键原则汇总

1. **只输一根K线**：每笔新开仓设止损
2. **白线之上持股**：跌破白线就卖
3. **盈转亏必须止损**：铁律
4. **放量只在上涨中有意义**：下跌看K线不看量
5. **地量+B1=最佳买点**
6. **倍量=增量资金入场**
7. **守恒破坏=交易价值**
8. **走横是间接对称核心信号**
9. **控制回撤三要素**：快速止损、果断放飞、仓位管理
10. **永远不满仓**：用仓位切换应对市场变化

## 第五层：进阶策略与风险控制

### 5.1 量比选当日最强（Level3-Level5体系）

**核心定义**：
- Level1 = B1（压抑拐点/底部第一根）
- Level2 = 异动（关键K/暴力K/倍量柱出现）
- Level3 = 当日最强（量比排名前列的强势股）
- Level4 = B2（B1之后的再次启动）
- Level5 = 葵花宝典（最高级别强势形态）

**识别条件**：
- 量比在开盘后快速放大
- 股价涨幅靠前
- 有板块效应配合

**关键规则**：
1. 只做上升趋势的票，股价必须在BBI线之上
2. 选择有板块效应的龙头股
3. 必须是缩量回调企稳后才能买入
4. 量比选股核心：找当日最强板块中的领涨股
5. 配合KDJ的J值打到13以下更佳

**止损位**：入场K线最低价下方3-5个点

### 5.2 单针下20战法（KDJ+机构/散户线）

**核心定义**：
单针下20是散户偷袭机构的超短线策略，通过观察机构线（红线）和散户线（白线）的行为变化，当散户线被洗到20以下而机构线仍在80以上时，代表机构筹码稳固而散户被洗走，这是短线的最佳入场时机。

**识别条件**：
- 散户线（白线）往下打穿20
- 机构线（红线）保持在80以上
- 股价处于上升趋势中

**关键规则**：
1. 买入时机1：单针下20标准形态出现后，次日开盘价入场
2. 买入时机2：白线回到20以上，红线保持在80以上，两者同时往上时入场
3. 买入时机3：深V形态完成后，股价突破V顶时入场
4. 买入时机4：双V形态（W形态）突破颈线位时入场
5. 买入时机5：结合KDJ的J值打到负值时配合入场
6. 买入时机6：在上涨趋势中，股价回踩BBI线不破时入场
7. 买入时机7：双线归零后，股价重新站上均线时入场
8. 买入时机8：四线归零后，次日股价高开高走时入场

**止损位**：
- 止损规则1：设在入场K线的最低点下方1-2个点
- 止损规则2：如果次日没有脱离成本线，开盘就卖出
- 止损规则3：买入后股价跌破入场K线的最低点，无条件止损
- 止损规则4：止损幅度一般控制在2%左右
- 止损规则5：如果买入后股价涨幅超过3%，可以将止损位上移到成本线
- 止损规则6：连续两次止损后暂停交易，调整状态

---

### 5.3 牛市逃顶信号（S1/S2/S3详细规则）

**核心定义**：
牛市逃顶是指在股票上涨趋势末端，通过识别特定的技术信号（S1、S2、S3）来规避系统性下跌风险，实现利润锁定和资金保护的交易策略。核心是通过S1、S2、S3三个阶段的卖点确认来分批卖出股票。

**识别条件**：

| 信号 | 特征 | 阶段 |
|------|------|------|
| **S1** | 连续加速后出现放量阴线/长上影线 | 第一次预警卖出 |
| **S2** | 反弹做双头后在前高放量位置卖出 | 确认卖出 |
| **S3** | 确认顶部结构后全部卖出 | 最后的全身而退 |

**关键规则**：
1. 没有谁能够精准逃顶，精准逃顶说明交易系统不行
2. 单顶不是顶，需要看双头确认
3. 宁可信其有，不可信其无，宁可走错也要走
4. 放量是改变趋势的信号，缩量是趋势延续的信号
5. 牛市中的背离会再背离，主要看量能
6. S1是放天量的巨阴线，S2是顶背离金叉空，S3是反抽失败
7. 放巨量的下沿一定会打到（祖宗之法）
8. 反抽先看黄线（60日线），再看巨量K线下沿
9. 小票走成丑图形直接止损，不用等S1、S2确认
10. 大票S1卖3分之一后，如果S2确认失败，止损位设在S2反弹的最高点之下

**止损位**：
- B1买入后如果跌破入场K线最低点，止损退出
- 如果股价放量跌破BBI线，止损退出

### 5.4 主力出货六种方式（识别出货形态）

**核心定义**：
主力出货是指个股在上涨过程中，主力资金通过特定技术图形和量价关系，将持仓筹码在高位派发给散户的过程。识别主力出货形态是保护利润的关键。**主力出货是一个过程，不会当天出完**，反复拉高出货是常态。

**六种出货方式**：

| 序号 | 类型 | 核心特征 | 识别要点 |
|------|------|----------|----------|
| **S1** | 加速后单日放天量大阴线 | 连续上涨加速后出现放天量巨阴，跌幅5%以上 | 出现在最高点当天，成交量创近期天量 |
| **S2** | 加速后次高点突然巨量长阴 | 前一日最高点缩量正常，次交易日突然巨量跌停 | 出货更突然果断，往往伴随利空或资金链断裂 |
| **第三种** | 新高之后连续阶梯放量下跌 | 价格阶梯下跌，成交量阶梯放大 | A股独有博弈思路，越走越低 |
| **第四种** | 双头双放量巨阴 | 两次头部都放巨阴 | 中盘股常见，双头位置是最后逃命机会 |
| **第五种** | 顶部绿长红短 | 绿柱持续长于红柱 | 适用于大盘股，主力性格温和慢慢出货 |
| **第六种** | 综合出货方式 | 多种方式组合 | 超级大盘股，顶部时间跨度长 |

**识别条件（精选）**：
1. 观察个股是否经历明显**加速上涨阶段**（连续大阳线或涨停）
2. 加速后出现**放天量的大阴线**，成交量为近期最大
3. 大阴线当天**跌幅要足够大**（通常5%以上），不能是小阴线
4. 判断是S1还是S2——S1是最高点当天放天量大阴线，S2是次高点突然反转
5. **次日观察是否低开或继续下跌**，确认出货信号
6. 观察是否出现**连续阶梯放量下跌**——新高后连续压着卖
7. 识别**双头形态**——两个头部都出现放量巨阴
8. 观察是否出现**绿肥红瘦形态**——绿柱长红柱短

**关键规则（买入/止损）**：

**卖出时机**：
- S1信号出现当天，**必须至少减仓一半或全部卖出**
- S2信号出现当天，**必须立即减仓或清仓**
- 次日如果低开或下跌，**继续减仓不要犹豫**
- **连续阶梯放量下跌确认后卖出**
- **绿肥红瘦形态确立后卖出**
- **双头位置是最后逃命机会**，必须走
- 跌破白线（短期趋势线）必须止损

**买入时机**：
- 必须等**B1信号出现**才能买入
- 或等B2/B3信号出现再买入
- 没有B1/B2/B3信号，**坚决不进场**
- 只做典型图形，不做磨磨唧唧的走势

**止损规则**：
- S1大阴线当天就是止损点，**跌破大阴线最低价必须止损**
- S2次高点巨量长阴当天，次日低开即止损
- **收盘跌破黄线时止损**
- 大阴线后反包失败，出现第二根大阴线时必须止损

**核心原则**：
1. 宁可信其有，不可信其无，**宁可卖飞不要被套**
2. **假阴真阳一律当阴线处理**，不要抱侥幸心理
3. 盘子越大，出货方式越综合，可能同时出现多种出货方式
4. **白线都不要了，黄线也不要了，说明主力真走了**
5. **顶部只有一个，背离可以有无数个**，不要看指标出货
6. 量价位置关系是判断出货的**核心**，不要依赖MACD、KDJ

**止损位**：出现S1信号后至少卖一半，跌破大阴线最低价必须止损

### 5.5 防卖飞策略

**核心定义**：
防卖飞策略是帮助投资者在持股过程中避免错误卖出的方法。**空位三分必须投进**——没有触发任何减仓或清仓条件的情况下卖出，就是踏空。牛市多急跌是正常现象，时不我待盘中洗盘或隔日洗盘，震仓震的是对手盘（机构、大资金），不是震散户。

**四等马分类（持股评分系统）**：

| 分类 | 定义 | 特征 | 操作 |
|------|------|------|------|
| **特级马** | 买入后每天都是阳线 | 收盘价天天上升，不管阴阳假阴真阳都算阳线 | 拿住不动，继续持有 |
| **一等马** | 整体重心往上走 | 收盘价趋势上升为主，即使横盘但低点逐步抬高 | 拿着不动，等待趋势反转 |
| **低等马** | 买入后腻腻歪歪 | 横盘不涨，不破止损又不涨 | 达到预期涨幅就卖出 |
| **草泥马** | 买入后打止损或出现SB1 | 触及止损，出现SB1信号 | 闭眼拍，不纠结 |

**对称类型（关键形态）**：

| 形态 | 特征 | 操作意义 |
|------|------|----------|
| **假阴真阳** | 收盘价高于前一天涨停板但K线收阴，成交量放量 | 第二天**大概率无量涨停**，持有或买入 |
| **四分之三阳线** | K线实体覆盖前一天四分之三以上，成交量缩半量 | **加仓点**，往后概率大 |
| **四分之三阴线（绿帽子）** | K线实体覆盖前一天四分之三以上，成交量缩半量 | **70%以上概率假突破**，会往下走 |
| **放量涨停后缩量小阳线** | 涨停突破后第二天缩量小阳线，量能萎缩至前一天一半 | **最完美的持股图形**，筹码稳定 |

**识别条件（精选）**：
1. 判断是否在持股过程中**没有触发任何减仓或清仓条件**
2. 检查是否属于策略范围内的**正常波动**（回调0.5%-1%正常）
3. 识别是否出现**假阴真阳形态**（收盘价高于前一天涨停板但K线收阴）
4. 判断是否为**四分之三阴阳线**（实体覆盖前一天四分之三以上）
5. 观察成交量是否**缩半量**（当天成交量是前一天的一半左右）
6. 检查股价是否维持在**BBI线**以上
7. 识别是否存在**四分音量线的危险信号**（70%概率假突破）

**每日持股检查手册**：

| 规则 | 核心要点 |
|------|----------|
| **规则一** | 主升浪阶段忽略盘中冲高回落，所有冲高回落都当吓唬你，真正的顶只有一个 |
| **规则二** | 当天下杀后尾盘快速收回是强庄股特征，收回一半以上说明强 |
| **规则三** | 不要在下杀中卖出，一分钟五分钟砸到跌停不要卖，有本事打你止损再卖 |
| **规则四** | 大盘突然下杀时不要草率处理强势股，早盘跟大盘往上说明主力想做多 |
| **规则五** | 缩量小阴线再等一天，涨多了回调1-2%很正常，只出时间不出钱 |
| **规则六** | 完美形态不破BBI线就拿住，不要主观臆断，物来则应过去不留 |
| **规则七** | 不要主观判断，不猜顶不猜涨跌，按系统信号操作 |

**评分标准（五分制）**：

| 分数 | 定义 | 操作建议 |
|------|------|----------|
| **五分** | 价格连续抬高，没有出现卖点 | 拿住不动，可减仓（无强制要求） |
| **四分** | 形态不完美但趋势还在 | 拿着不动，忽略日内波动 |
| **三分** | 可走可留，但没有概率优势 | 可以卖一半，有浮盈不能卖 |
| **二分** | 情况不太妙，趋势可能即将破位 | 准备止损，等待明确信号 |
| **一分** | 已经残了，情况比较糟糕 | 考虑止损，不能继续持有 |
| **零分** | 已经死了，彻底破位 | **必须止损**，无悬念 |

**关键规则**：
- **空位三分必须投进**：没有出现任何该卖出迹象的情况下，不要轻易卖出
- **假阴真阳第二天大概率无量涨停**
- **放量涨停后缩半量小阳线是最完美的持股图形**
- **BBI线是不破的生命线**
- **只看收盘价，不看盘中波动**，回归第一性原理
- **忽略一切技术指标**，金叉死叉在中国市场不管用
- 浮盈后要有耐心，让利润奔跑，不要赚点小钱就跑
- **不涨就拍和跌破止损是两种能赚大钱的图**

**止损位**：出现S1信号或跌破白线/BBI线时执行卖出

### 5.6 挖坑填坑麒麟会

**核心定义**：
**放弃向上幻想，专注挖坑和填坑**。大A只有下去才能上来，不要期望指数涨到3400、4000点。挖坑填坑是指主力在拉升前故意打压股价制造恐慌，迫使散户交出筹码，然后快速拉升股价回到成本区的过程。**填坑出坑是散户跟随主力低成本买入的核心机会**。

**麒麟会运作四步流程**：

| 阶段 | 特征 | 关键信号 |
|------|------|----------|
| **建仓** | 股价从低位开始连续上涨，在坑里横盘 | MACD绿变红，DIF白线上零轴，放量关键K |
| **洗盘** | 股价大跌但仓位不减 | MACD死叉但白线仍在零轴上方，走N型结构回撤 |
| **拉升** | 连续小阳推升，盘中可能出现大阳 | MACD零轴上二次金叉（主升浪），空中加油形态 |
| **出货** | 仓位线连续下降，主力开始抛售 | MACD顶背离或由红变绿，成交量放出天量 |

**麒麟会分类**：

| 类型 | 特征 | 成功率 |
|------|------|--------|
| **成功型麒麟会** | 有足够资金实力控盘，有清晰题材支撑 | 40% |
| **被套型麒麟会** | 资金实力不足，无法有效拉升 | 40% |
| **炮灰型麒麟会** | 没有实力却强行坐庄 | 20% |

**对称类型（实战形态）**：

| 形态 | 特征 | 实战意义 |
|------|------|----------|
| **强势建仓型** | 白线始终在零轴之上，回调缩量，低点不断抬高 | 志在长远，可持续关注 |
| **横盘整理型** | 股价在一定区间内横盘波动，量能极度萎缩 | 横盘末期放量突破是信号 |
| **挖坑后拉升型** | 快速下跌制造恐慌，V型反转收复失地 | 出坑时伴随放量长阳是最佳买点 |
| **波段操作型** | 沿着BBI线震荡上行，回调到BBI线附近获支撑 | 回调缩量是加仓机会 |

**识别条件（精选）**：
1. 打开股票MACD指标，将参数调整为**12-26-9**
2. 观察**白线（DIFF）是否在零轴之上**，这是判断主力是否在场的首要条件
3. 寻找**放量关键K线**（涨幅5%以上），这是主力入场的成本区
4. 观察回调过程中是否**缩量**，并且**J值打到-10以下**，这是送钱机会
5. 确认回调**不破关键K线最低点**，同时**股价不破BBI线**
6. 出坑信号识别：**股价放量突破前高**，MACD白线加速向上
7. 观察成交量是否配合，**上涨时量能需放大至5日均量1.5倍以上**
8. **持股待涨，期间不做T、不频繁操作**，直到出现明确的出货信号

**关键规则（买入/止损）**：

**买入时机**：
- **MACD DIF白线在零轴以上**，这是做多的前提条件
- 出现**勾大负值（J值到-7以下）**时，可考虑分批建仓
- **MACD零轴上二次金叉**出现时，是主升浪的确认信号
- **股价站上BBI线且成交量配合放大**时跟进
- **填坑过程中，股价从坑底起来时买入**
- **红肥绿瘦**（阳线放量、阴线缩量）的股票可持续关注
- 放量突破前高时买入，此时是典型的出坑信号

**止损规则**：
- 止损位置设在**入场K线的最低点之下3-5%**
- **跌破BBI线必须止损**，不能抱有任何幻想
- **MACD白线跌破零轴时必须止损**
- **单日跌幅超过7%且放量时必须止损**
- 买入后股价不涨反跌，**跌幅超过5%必须止损**
- **亏损超过7%必须止损，亏损超过10%强制止损**

**核心原则**：
1. **放弃向上幻想，专注挖坑和填坑**，这是第一原则
2. 大A只有下去才能上来，不要期望指数涨到3400、4000
3. **MACD DIF白线必须在零轴以上**才有机会，零轴以下反弹很难
4. **麒麟会运作四步流程**：建仓→洗盘→拉升→出货，缺一不可
5. **勾大负值是超卖信号**，可考虑分批建仓
6. **不要对股票产生感情**，205破位（涨幅200%位置）必须走
7. **红肥绿瘦是主力建仓的标志**
8. **跌破BBI线就止损**，这是纪律
9. **回调缩量是好事**，说明主力没有出货，可以继续持有或加仓
10. 上涨途中**回调不破零轴就是倒车接人**，是送钱机会

**止损位**：挖坑低点下方3-5个点，或跌破BBI线必须止损

### 5.7 异动选牛股（Level2核心识别）

**核心定义**：
异动选牛股是通过识别个股的技术面异动（关键K、暴力K、倍量柱）来筛选强势牛股的方法。**异动=突然放量+量随价升**，异动是选股的核心逻辑，无论B1还是B2策略，本质都是寻找异动的股票。Level2级别的异动意味着有明确的主力建仓证据。

**异动形态分类**：

| 形态 | 特征 | 实战意义 |
|------|------|----------|
| **断量（首选）** | 高位直接断崖式下跌，成交量缩至1/3-2/5 | 随时可能启动，无需长时间横盘 |
| **阶梯量（观望）** | 高位连续阶梯式下跌，每根K线成交量逐步缩小 | 需要2周以上盘整期，短期启动概率低 |
| **美人胚子型** | 假阴真阳+成交量放大+KDJ勾起大负值 | 强势启动信号 |
| **一览众山小型** | 长期横盘后突然放量异动，突破横盘区间 | 横盘越久可靠性越高 |
| **堆量启动型** | 异动后成交量持续堆量放大 | 量能堆积足够支撑后续拉升 |
| **强壮型** | K线实体强壮饱满，量能充沛，走势流畅 | 志在长远，主力耐心建仓 |

**异动强度分类（NBA球员类比）**：

| 类型 | 强度 | 特征 |
|------|------|------|
| **詹姆斯型** | 最强 | 走势最强，持续放量 |
| **乔丹型** | 强 | 有明显的主力运作痕迹 |
| **拉希德华莱士型** | 中等 | 强度一般 |
| **徐杰型** | 最弱 | 异动高度有限，属于一日游 |

**识别条件（精选，Level2核心）**：
1. **判断市场整体状态**——观察是热身阶段还是924行情阶段
2. **识别机构入场信号**——突然出现大量买单和放量行为
3. **观察板块轮动方向**——留意哪个板块开始启动
4. **选择龙头股**——在启动板块中选择走势最强、最先涨停的股票
5. **使用选股指标筛选**，找出**J值在13以下**的股票
6. **观察成交量是否明显萎缩**（较前一交易日缩量1/3-2/5）
7. **检查K线形态**，是否为小实体K线（十字星、小阴小阳）
8. **确认当前价格处于相对低位**（从高点下跌30%以上）
9. **查看60日线位置**，确认股价已站上或接近60日线
10. **分析前期是否有建仓波**（60日线附近的放量上涨）
11. **排除阶梯量形态**，选择断量形态的股票
12. **使用多因子模型打分**，70分以上可考虑买入
13. **验证60日线是否向上拐头**，确认建仓波健康度
14. **确认B1信号出现**（KDJ指标勾起大负值），在地量地价位置寻找B1入场点
15. **验证异动后是否有堆量现象**，堆量足够支撑后续拉升
16. **检查BBI线是否同步走平或向上**

**交易规则**：

**买入时机**：
- **在板块启动初期买入龙头股**，等待板块轮动上涨
- **B1买入需配合守恒被破坏+走横+B1信号**（KDJ勾起大负值）
- **70分以上股票可考虑买入**，分数越高确定性越强
- 出现放量阳线且伴随**J值上穿**时买入
- **突破关键阻力位**（如前高、60日线）时买入
- **缩量回调至重要支撑位不破**时买入
- **第二天反包前一天阴线**时买入（强势信号）
- **堆量形成后缩量回踩**到B1是较好买点
- **强势股回调到BBI线附近获得支撑**时买入

**止损规则**：
- 止损位置设在**入场K线的最低点之下**
- 跌破关键支撑位**立即止损**
- **单只股票亏损超过7%必须止损**
- **跌破60日线无条件止损**
- **跌幅超过7%强制止损**
- 出现顶部信号（如放巨量假阴真阳长上影）时**减仓或止损**
- **买入后三天内不涨，强制止损换股**（资金效率原则）

**关键原则**：
1. **异动是选股的核心**，记住"异动"两个字就是核心策略
2. **龙头股分数在70以上，杂毛股分数在70以下**
3. **分散投资**，不要把所有资金押在单一股票或板块上
4. **不能追涨已大涨的股票**，涨幅超过25%风险较大
5. **资金效率很重要**，三天不涨就换别的股票，不要死扛
6. **只做强势股，不做弱势股**，形态完美是前提
7. **打分要在80以上**，标准严苛，不完美不买

### 5.9 散户思维克服（心态管理）

**核心定义**：
散户在股市中赚不到钱的根本原因**不是技术分析不到位，而是思维模式存在系统性缺陷**。散户必须克服的五种错误思维模式，建立正确的投资认知。新股民是最危险的群体，亟需纠正五种思维偏差。

**五种错误思维**：

| 序号 | 思维类型 | 定义 | 典型表现 | 危害 |
|------|----------|------|----------|------|
| **1** | 线性思维 | 认为股票上涨必须按照特定顺序发生 | 认为必须先有一致性再上涨、等完美图形 | 错过大量上涨机会，只在高位追入 |
| **2** | 对立思维 | 认为只能持有某类股票 | 持有白酒就认为科技股是敌人 | 心态失衡，频繁踏空 |
| **3** | 情绪化思维 | 凭感觉做决策 | 今天亏了1%感觉像亏20% | 高买低卖，心态崩溃 |
| **4** | 急于求成思维 | 刚入市就期望快速赚钱 | 三天不涨就换股，期望一夜暴富 | 频繁交易，亏损累累 |
| **5** | 追求完美思维 | 必须等到所有条件都满足才动手 | 等一致性出来再买，结果涨太高 | 要么不敢买，要么买在最高点 |

**克服方法**：

| 思维类型 | 克服方法 |
|----------|----------|
| **线性思维** | 理解股市是**不确定性市场**；接受任何条件组合都可能导致上涨；一致性只是加分项不是必要条件；关键是图形是否好看 |
| **对立思维** | **不要对立**，市场是轮动的；每个阶段都有不同的主线；不同板块之间是轮动关系 |
| **情绪化思维** | **严格按照数据操作**，不要带情绪；理性看待账户波动；把情绪从交易中剔除 |
| **急于求成思维** | 理解赚钱需要**时间和周期**；先学习方法是前提；把十张图好好研究清楚 |
| **追求完美思维** | 没有100%完美的图形；一致性是艺术不是科学；图形好看就能买；接受不完美才能抓住机会 |

**识别条件（精选）**：
1. 检查是否设定了**"一年回本"或"赚多少"的错误目标**
2. 反思是否每天**盯着热点股而忽略自己的持仓**
3. 评估是否在操作**超过心理承受能力的资金**
4. 检查是否因为**短期波动而心态崩溃**
5. 反思是否有**"一买就必须涨"的线性思维**
6. 检查是否经常**抱怨市场而不是反思自己**
7. 检查是否在**上涨后盲目乐观**
8. 检查是否在**下跌后恐慌**
9. 检查是否对**陌生股票有排斥**
10. 检查是否在**追涨杀跌**
11. 检查是否**遵守操作纪律**
12. 检查是否**只相信盘面**

## 独门对称战法（10.22系列）

### 核心定义
基于杨振宁「对称性支配相互作用」理论，结合多空守恒原理，寻找走势不完美（守恒被破坏）的位置进行交易的核心战法。**只在守恒被破坏的位置才有交易价值**。

### 对称类型与应用

| 类型 | 用途 | 特征 |
|------|------|------|
| **时间对称** | 择时 | 上升周期对应下降周期，判断市场整体所处阶段 |
| **空间对称** | 选股 | 直接对称（A字杀）、间接对称（N型回调） |
| **形态对称** | 入场点 | 轴对称（突破）、中心对称（横盘）、走横 |

### 空间对称详解

**直接对称**：
- 定义：A股杀，走势呈现A字形，左边上涨后右边直接跌回去
- 交易建议：A股杀下来的票不要碰，如果非要买必须第二天涨停

**间接对称**：
- 定义：A股起来后回调只回一半，被多头力量顶上去，形成N型结构
- 交易建议：间接对称是最常见的交易机会，等待B1信号

**守恒被破坏标志**：
- 原本应该下跌的走势突然走横或上涨
- 斜率发生明显改变
- 横盘后出现突破K线

### 形态对称详解

**轴对称**：以一条水平线为对称轴，左右两边形态相似，做突破行情

**中心对称**：以一个中心点为中心旋转对称，用于横盘震荡区间

**走横（核心价值）**：股价在一个区间内小幅波动，**走横是最有价值的买入点**

### 买入规则

| 规则 | 条件 |
|------|------|
| 规则1 | B1买入需配合三个条件：守恒被破坏 + 走横 + KDJ的J值勾起大负值 |
| 规则2 | 间接对称的位置，回调只回一半被多头顶上去 |
| 规则3 | 走横的位置最有价值，等待横盘后出现B1信号 |
| 规则4 | 斜率发生改变的位置，原本应该下跌但没有下跌 |
| 规则5 | 底部走横后出现放量大阳线打破平衡的位置 |
| 规则6 | 下跌趋势中连续下跌后出现不创新低的K线 |
| 规则7 | 突破前高后回踩不破前高的位置 |
| 规则8 | B2突破时结合对称理论判断真假突破 |

### 止损规则

| 规则 | 条件 |
|------|------|
| 规则1 | 止损位置设在入场K线的最低点下方 |
| 规则2 | 如果跌破白线（短期趋势线）必须止损 |
| 规则3 | 如果走横后跌破关键支撑位要止损 |
| 规则4 | A股杀下来的票买错第二天必须止损 |
| 规则5 | 买入后两天内没有出现预期走势要止损 |
| 规则6 | 出现S1信号时是止损或止盈的信号 |
| 规则7 | 斜率改变后走坏要果断止损 |

### 关键原则（20条）

1. 只在守恒被破坏的位置才有交易价值
2. 走势必对称，但要找不完美的走势
3. A股杀下来的票不要碰，除非第二天涨停否则必须走
4. **走横是最有价值的买入点**
5. 斜率改变是多空力量失衡的重要信号
6. 时间对称用于择时，空间对称用于选股，形态对称用于入场
7. B1买入必须配合守恒被破坏、走横、J值勾起大负值三个条件
8. 对称完美后要放飞，不要期待吃到全部利润
9. 小级别对称要服从大级别对称
10. 空间越大、时间越长的对称确定性越强
11. 横盘期间没有交易价值，要等打破平衡的K线出现
12. 看图要画N型结构，找高低点
13. 放量突破和缩量回调都是信号
14. 右侧交易一律是短线，必须带止损
15. 不要在横盘震荡区间频繁交易
16. 不要听任何内幕消息，坚持自己的交易系统
17. 心态管理比技术更重要
18. 宁可错过，不要做错
19. 持续学习但不要过度学习
20. 实战中积累经验，三到五年才能真正掌握

### 失败场景

1. 买入后连续横盘不走趋势，浪费资金时间成本
2. A股杀下来的票买入后继续下跌
3. 走横后买入但继续横盘，没有等来上涨
4. 对称完美后没有及时放飞，利润回吐
5. 小级别对称失败，被大趋势吞没
6. 空间和时间不够的对称交易，胜率低
7. 逆势操作，在下跌趋势中找对称买点
8. 频繁交易，横盘期间不断操作

## 5.10 十张难看图形绝不能碰（3.1系列）

**核心定义**：
永远保持仓里的股票都是股价在白线和黄线之上、白线在黄线上方。十种难看图形是必须规避的卖出/禁买信号。

**核心理念**：均线不是支撑，是确认。均线要确认之后才有意义。

### 十种难看图形

| 序号 | 图形类型 | 特征 | 应对策略 |
|------|----------|------|----------|
| 1 | 高位跌破黄线 | 股价处于历史高位区，跌破黄线（20日均线） | 第一天就要走，连续两天跌破无条件离场 |
| 2 | 高位放量阴线 | 高位出现放量阴线 | 这是出货信号，股价会在其下方运行 |
| 3 | 长上影线（蜈蚣头） | K线出现长上影线 | 不好看的图形，不买入 |
| 4 | 大绿棒子 | 出现大阴线 | 不买入，等站起来再观察 |
| 5 | 高位S1出货信号 | 出现S1出货信号 | 宁可信其有不可信其无，优先卖出 |
| 6 | 空头排列破位205 | 高位空头排列跌破重要位置 | 走错也要走，不能扛 |
| 7 | 高位长期发散后破位 | 高位长期均线发散后跌破均线 | 不要抄底，立即止损 |
| 8 | 击穿对手盘后不走 | 击穿对手盘后不死心等太久 | 只忍一根，不能忍3-7根 |
| 9 | 高位横盘破位 | 高位横盘后跌破黄线 | 横盘期间的每次跌破都可能是一轮大跌开始 |
| 10 | 下跌趋势中的反弹 | 白线始终在黄线下方运行 | 任何反弹都是离场机会，不是入场机会 |

### 均线系统

| 均线 | 周期 | 用途 |
|------|------|------|
| 白线 | 短期（5日） | 短线操作参考 |
| 黄线 | 中期（10日/20日） | 波段操作参考 |
| 粉线 | 长期（60日） | 中长期趋势 |
| 绿线 | 超长期（240日） | 牛熊分界线 |

### 买入信号体系

**B1买入条件**：
- 规则：守恒被破坏 + 走横 + B1信号（KDJ勾起大负值）
- 触发：KDJ指标J值勾起大负值，同时股价走横且守恒被破坏
- 动作：在B1信号出现时买入

**B2买入条件**：
- 规则：单根中长阳（大于4%）无上影线或小上影线，放量，前面无密集堆量
- 触发：出现单根涨幅大于4%的中长阳线
- 动作：检查上影线是否足够短，前面是否无密集堆量，满足条件可买入

**S1出货信号**：
- 规则：S1出来之后，宁可信其有，不可信其无
- 触发：出现S1出货信号
- 动作：优先考虑卖出，宁可错过不要深套
- 注意：S1突破过去后，前面的S1就失效

### 交易纪律

**短线纪律**：
| 规则 | 说明 |
|------|------|
| 跌破白线就卖 | 短线操作时，跌破白线立刻卖出，跌破黄线更是卖出信号 |
| 两天不涨就拍掉 | 买入后连续两天股价没有上涨，立即卖出 |
| 专精图做两根 | 第一根进去，第二天9:30-9:37不拉起就卖 |

**波段纪律**：
| 规则 | 说明 |
|------|------|
| 高位跌破黄线必须走 | 连续两天跌破黄线无条件离场 |
| 高位空头排列破位205必须走 | 无论什么理由都要走 |
| 跌破关键K | 要么赌一根，要么就走 |

### 关键实战要点

- **均线交叉**：白线插上粉线有两种方式——要么带量拉升，要么横盘等待
- **多头排列**：低位多头排列有价值，高位多头排列不好说，只能搏一把并设止损
- **趋势识别**：白线之上的衰竭点没有意义；下跌趋势中的红柱没有意义
- **选股原则**：尽量在有钱的地方、有大哥在的地方去找B1、B2、B3

### 异动建仓核心规则

| 规则 | 触发条件 | 具体动作 |
|------|----------|----------|
| 异动建仓波涨幅控制在30%左右 | 个股出现异动建仓波时 | 建仓波涨幅最好控制在30%，正态分布最大概率落在30%位置，35-40%也可以但要谨慎 |
| 换手率控制30%原则 | 异动建仓波的大阳线换手率 | 大阳线换手率控制在30%左右，几根加起来不超过30%，单根不超过30% |

### 换手率标准

| 换手率 | 判定 | 操作 |
|--------|------|------|
| 30%左右 | 完美 | 继续关注 |
| 50-60% | 偏高 | 谨慎观察 |
| ≥70% | 过高 | 不做，可能A杀 |

### 30秒诱多诱空识别

- **诱多特征**：分时图快速拉高后下杀，跌破零轴
- **诱空特征**：分时图快速下杀后拉回，收复零轴
- **洗盘确认**：次日高开 = 洗盘成功；次日低开 = 真跌

### 筹码峰应用

- **牛市**：筹码峰意义不大，涨了再涨
- **熊市**：筹码峰有参考价值，跌破下沿机构全被套
- **蹦极**：跌破后快速收回，机构可能自救

## 5.12 九篇心法精讲（3.11系列）

**核心定义**：
市场交易中的反心理特征与实战交易心理法则。主力资金与散户之间的博弈关系，主力利用散户的心理弱点进行反向操作。

### 九篇心法核心框架

| 篇数 | 主题 | 核心关键词 |
|------|------|------------|
| 1 | 太过完美而不敢买 | 坚决买入、严格止损 |
| 2 | 忽视热点切换 | 忽略偏见、简单思考 |
| 3 | 日内假反转 | 盈亏比、8日成本线 |
| 4 | 上次失败影响下次 | 独立判断、节奏 |
| 5 | 盲目抄底 | 策略优先、不盲目 |
| 6 | 以成本对待转势 | 站在主力角度 |
| 7 | 舒服=风险 | 不确定性、见好就收 |

| 9 | 反制研究 | 不确定性、3/4量阴线 |

### 核心交易铁律

- **3/4量阴线**：买入后当日出现3/4量阴线 → 次日冲高走人
- **不确定性思维**：买进去后看看会发生什么
- **物来则应，过去不留**：不要被心理作用击倒
