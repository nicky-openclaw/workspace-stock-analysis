## 执行规范快速参考

**评分标准（100分制，上限100）**：
- 涨停 +30 / 涨幅5-9% +15 / MA20向上 +10 / 多头排列 +10
- 放量 +10 / 砖型走强 +20 / 砖型>100 +5 / B1 +20 / B2 +15

**三大禁忌**：
- ❌ 不用腾讯实时涨幅字段（必须K线计算）
- ❌ 不用内置browser工具（必须agent-browser skill）
- ❌ 不自编B1/B2公式（必须library.py）
