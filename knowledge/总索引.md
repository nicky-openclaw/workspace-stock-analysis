## 常用规则速查

### 买入信号
| 信号 | 条件 |
|------|------|
| B1 | J<13 + 白上黄上 + 地量 |
| B2 | 涨幅>4% + 放量 + 黄线附近 |
| B3 | 对称位置二次启动 |

### 卖出信号
| 信号 | 条件 |
|------|------|
| S1 | 高位放量阴线/长上影 |
| S2 | 反弹到前高不过 |
| 3/4量阴线 | 放量下跌超3/4实体 |

### 仓位规则
| 市场 | 仓位 |
|------|------|
| 多头(活跃市值≥4%) | 20-25%/票 |
| 空头(活跃市值<-2.3%) | 仅B1轻仓 |
