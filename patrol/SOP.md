## 二、执行步骤

### Step 1: 读取昨日选股

从 `patrol/YYYYMMDD/` 读取选股报告，提取股票代码列表

```
patrol/
├── 20260316/
│   ├── 启动K选股报告_20260316.md
│   └── 砖型图选股报告_20260316.md
```

### Step 2: 获取数据

**优先**: 腾讯API（脚本 `scripts/patrol_review_data.py`）

```python
# 快速批量获取基础数据
from scripts.patrol_review_data import get_basic_data_from_tencent

stocks = [("300051", "琏升科技", "sz"), ...]
data = get_basic_data_from_tencent(stocks)
```

**API失败时使用 agent-browser**:

```bash
# 打开股票页面
agent-browser open https://quote.eastmoney.com/sz300042.html

# 获取快照
agent-browser snapshot -i

# 从输出中解析数据
```

**agent-browser 获取详细数据的步骤**:
1. `agent-browser open https://quote.eastmoney.com/sz{code}.html`
2. `agent-browser snapshot -i`
3. 从输出中解析：
   - 最高/最低价
   - 成交量、换手率
   - 量比
   - 龙虎榜数据
   - 成交额是否创历史新高
   - 所属板块

### Step 3: 计算对比指标

| 指标 | 计算方式 | 意义 |
|------|----------|------|
| **相对大盘** | 今日涨幅 - 大盘涨幅 | 正=强于大盘 |
| **量能比** | 今日成交量 / 昨日成交量 | >1.5放量，<0.7缩量 |
| **开盘方式** | (今日开盘价 - 昨日收盘价) / 昨日收盘价 * 100% | >2%高开，<-2%低开 |
| **日内走势** | (收盘价 - 开盘价) / 开盘价 * 100% | >0高走，<0低走 |
| **破位信号** | 今日最低价 < 昨日涨停价 - 5% | 跌破关键支撑 |

### 问题分析（核心）

每只股票需要分析以下维度：

#### 1. 题材持续性
- 昨日涨停的催化剂是什么？（政策/业绩/消息/板块联动）
- 今日是否还有消息面支撑？
- 题材属于一日游还是持续性题材？

#### 2. 资金行为
- 是否有机构买入？（龙虎榜机构席位）
- 还是游资主导？（散户榜/无榜）
- 次日主力资金是净流入还是净流出？

#### 3. 市场情绪
- 昨日涨停股的整体溢价率
- 板块内其他涨停股的表现
- 市场周期位置（上升/震荡/下降）

#### 4. 技术位置
- 是否在关键压力位？
- 是否有支撑位？
- 量能是否健康？（缩量回调健康，放量下跌危险）

#### 5. 开盘方式归类
| 模式 | 特征 | 结论 |
|------|------|------|
| 持续强 | 高开高走+缩量+收涨 | ✅ 继续持有/买入 |
| 洗盘 | 低开高走+缩量+收涨 | ⚠️ 可持有 |
| 出货 | 高开低走+放量+收跌 | ❌ 卖出 |
| 一日游 | 昨日涨停+今日涨幅<0 | ❌ 卖出 |
| 破位 | 今日最低价<昨日涨停价*0.95 | ❌ 止损 |

### Step 5: 对照分析

- **同批次涨幅对比**: 昨日选出的股票今日平均涨幅
- **同板块对比**: 选出的股票 vs 同板块其他涨停股
- **板块资金**: 板块主力净流入/净流出

## 三、输出格式

**重要**: 报告必须生成飞书文档，不是纯文本！

### 生成飞书文档

```python
from feishu_create_doc import create_doc

content = generate_markdown_report()  # 生成完整Markdown报告
doc_url = create_doc(title="选股复盘 - YYYYMMDD", markdown=content)

# 发送文档链接到飞书群
message send to飞书群: doc_url
```

### 报告内容要求

1. **整齐的表格排版**（使用Markdown表格）
2. **完整的分析维度**：
   - 大盘情况
   - 昨日选股今日表现（全部股票）
   - 归因分析（分类统计+开盘方式分析）
   - 深度分析（重点股票）
   - "哪出了问题"根因分析
   - 总结

### 示例输出

生成飞书文档: https://www.feishu.cn/docx/xxx
