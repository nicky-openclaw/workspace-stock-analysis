# 视频知识库导入规范

## 触发条件
用户告知"有新的视频分析完成"时执行

## 导入流程

### 第一步：检查输出目录
```bash
# 位置
~/Desktop/VideoAnalysisOutput/    # 报告和JSON
~/Desktop/PublicFrames/           # 帧图片
```

### 第二步：确认新系列
```bash
# 列出桌面输出目录
ls ~/Desktop/VideoAnalysisOutput/

# 检查已导入的知识库
ls ~/.openclaw/workspace-stock-analysis/knowledge/系列报告/
```

### 第三步：质量评估（必做）
按SOP 2.0标准检查报告质量：
| 指标 | 要求 |
|------|------|
| 核心内容 | 完整 |
| 触发条件 | 明确（如：加速后天量+大阴线） |
| 具体动作 | 可执行（如：减仓50%/清仓） |
| 质量评级 | ≥80% 才可导入 |

### 第四步：分类导入
| 类型 | 导入位置 |
|------|----------|
| 技术分析类 | `knowledge/系列报告/` |
| 出货/逃顶类 | `knowledge/系列报告/` |
| 心态思维类 | `knowledge/系列报告/心态思维类/` |

### 第四点五步：导入原始知识库（必做）
```bash
# 从VideoAnalysisOutput目录复制原始JSON
cp ~/Desktop/VideoAnalysisOutput/[系列名]_知识库.json \
   ~/.openclaw/workspace-stock-analysis/knowledge/原始知识库/
cp ~/Desktop/VideoAnalysisOutput/[系列名]_*部分_知识库.json \
   ~/.openclaw/workspace-stock-analysis/knowledge/原始知识库/
```

### 第五步：导入报告文件
```bash
# 技术分析类
cp ~/Desktop/VideoAnalysisOutput/[系列名]_报告.md \
   ~/.openclaw/workspace-stock-analysis/knowledge/系列报告/
cp ~/Desktop/VideoAnalysisOutput/[系列名]_帧分析.json \
   ~/.openclaw/workspace-stock-analysis/knowledge/系列报告/

# 心态思维类
cp ~/Desktop/VideoAnalysisOutput/[系列名]_报告.md \
   ~/.openclaw/workspace-stock-analysis/knowledge/系列报告/心态思维类/
```

### 第六步：导入帧图片
```bash
BASE=~/.openclaw/workspace-stock-analysis/knowledge/images

# 判断类型
if [ "$系列名" 包含 "思维" ] || [ "$系列名" 包含 "心态" ]; then
    mkdir -p "$BASE/心态思维类"
    cp -r ~/Desktop/PublicFrames/[系列名]/ "$BASE/心态思维类/"
else
    mkdir -p "$BASE/帧图片库"
    cp -r ~/Desktop/PublicFrames/[系列名]/ "$BASE/帧图片库/"
fi
```

### 第七步：验证
```bash
# 确认报告导入
ls ~/.openclaw/workspace-stock-analysis/knowledge/系列报告/ | grep [系列名]

# 确认帧图片导入
find ~/.openclaw/workspace-stock-analysis/knowledge/images -name "[系列名]" -type d

# 统计帧数量
find ~/.openclaw/workspace-stock-analysis/knowledge/images -name "*.jpg" | wc -l
```

## 质量评级参考

| 级别 | 分数 | 处理方式 |
|------|------|----------|
| ⭐⭐⭐⭐⭐ | 90%+ | 直接导入 |
| ⭐⭐⭐⭐ | 80%+ | 可导入 |
| ⭐⭐⭐ | 60-80% | 需补充后导入 |
| ⭐⭐ | 40-60% | 暂不导入 |
| ⭐ | <40% | 不导入 |

## 注意事项
- 心态思维类单独放 `心态思维类/` 子目录
- 每导入一个系列，同步更新 MEMORY.md 的文件索引
- 帧图片命名格式：`p[部分]_[知识点]_[时间].jpg`
