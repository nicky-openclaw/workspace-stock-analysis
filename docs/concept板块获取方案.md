## 四、技术实现

### agent-browser 命令
```bash
# 打开个股页面
agent-browser open "https://quote.eastmoney.com/sh600498.html"

# 获取快照
agent-browser snapshot

# 提取概念（grep）
agent-browser snapshot | grep -i "概念"
```

### Python 封装脚本
创建 `get_concept.py` 脚本：
- 输入：股票代码列表
- 输出：概念板块字典
- 使用subprocess调用agent-browser
