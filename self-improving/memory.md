# HOT Memory — 股票分析Agent

> ≤100行核心教训区

---

## 框架有效条件（已验证）

| 模式 | 触发条件 | 行动 |
|------|---------|------|
| 启动K高效 | 主线板块明确+情绪好 | 积极参与 |
| 砖型图高效 | 个股突破+板块助攻 | 找砖型信号 |
| 框架失灵 | 大盘分化+主线不明确 | 谨慎选股 |
| 科创板风险 | 主力净流出 | 回避或严格止损 |

---

## 选股框架核心原则

- 启动K：昨日涨停/大涨 + 主线板块助攻 = 连续强势
- 砖型图：突破 + 量能放大 + 板块助攻 = 有效信号
- 两者都强调"板块助攻"，无助攻的个股独立行情难以延续

## 数据获取优先级

1. **mx-finance-search**（金融资讯/新闻/公告）— 额度有限但数据权威
2. **mx-stocks-screener**（智能选股/多维度筛选）
3. **mx-macro-data**（宏观经济数据）
4. 新浪/腾讯API（实时行情）— 基础数据
5. agent-browser（网页数据）— 备用
