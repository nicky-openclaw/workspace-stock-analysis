# 项目学习：大盘分析

## 分析框架

### 核心指标
1. **指数涨跌**：沪深300、上证、深证
2. **成交量**：两市合计成交额（vs昨日、vs5日均量）
3. **市场宽度**：涨停数量、情绪判断
4. **板块资金**：主力净流入/流出

### 企稳信号
- [ ] 指数连续3天以上不创新低
- [ ] 反弹时放量，调整时缩量
- [ ] 主线同一主线连续2-3天
- [ ] 弱势板块不创新低
- [ ] 外部环境配合
