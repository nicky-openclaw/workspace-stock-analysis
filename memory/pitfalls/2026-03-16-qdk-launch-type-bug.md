- **趋势延续型**：上涨趋势中回调后再次启动

  - MA20向上
  - 之前在高位运行（之前已在黄线上方一段时间）
  
- **趋势改变型**：之前下跌/横盘，今天第一次突破

- 如果之前已经在黄线上方运行一段时间 → 趋势延续型
