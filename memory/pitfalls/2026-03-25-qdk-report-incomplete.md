# Pitfall: QDK报告不完整

**日期**: 2026-03-25
**触发**: 用户指出报告不合格，缺少框架要求的内容

## 错误现象
1. 生成的飞书报告缺少关键板块：框架要求10个输出板块只写了2个
2. 本地报告文件也未按框架格式保存
3. 无法找到 qdk_scores.json 导致无法重建完整报告
4. 错误判断"feishu_create_doc工具未加载"，实际上只是message工具调用方式有误

## 根因分析
1. **跳过了Step 0确认清单**: AGENTS.md Rule 0要求开始前读取框架文件，没有执行
2. **路径记忆错误**: qdk_scores.json 实际在 `qdk_output/` 目录，但记忆认为是 patrol/ 目录
3. **错误汇报**: 发现工具调用失败后没有深究，直接报"工具未加载"
4. **报告生成过早**: 脚本输出"报告已保存"后就以为完成了，没有核对实际输出文件

## 解决方案
1. **严格执行Rule 0**: 每次任务前必须读取框架文件，逐项核对输出格式
2. **确认文件路径**: 脚本输出后立即检查实际文件位置，不要凭记忆
3. **深挖工具问题**: 工具调用失败时不要简单报"未加载"，要尝试直接调用工具
4. **写报告前核查**: 报告写入前对照框架文件逐项检查完整性

- Decision: 报告写入飞书前必须对照框架逐项核查，Trigger: feishu_doc write后
- Decision: qdk_scores.json 路径为 `qdk_output/qdk_scores.json`，Trigger: 读取评分数据时
