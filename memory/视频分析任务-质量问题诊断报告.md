# 视频分析任务质量问题诊断报告

> 写于：2026-03-07  
> 目的：反馈给视频分析 Agent，用于优化视频处理流程  
> 诊断依据：knowledge/video-source/ 目录下全部23个视频的输出结果

---

## 一、结论概述

**当前视频分析任务的输出质量整体不可用。** 知识库中大部分战法文件内容极度碎片化，无法支撑实际交易决策。根本原因在于三个环节全部存在缺陷：输入质量差、处理逻辑错误、输出格式设计失当。

---

## 二、问题一：输入端——ASR文稿质量极差（最根本原因）

### 症状
大多数视频的 transcript.txt 是 ASR（自动语音识别）逐秒直出，例如：

```
[0.00] 有一个导乱说在一个低空经济还能进吗
[6.64] 这个人就交给你们处置了好不好
[8.48] 我就不着了就你们来你们看着办吧
[25.60] 还没出呢是吗
[30.00] 这一天我都在看着你
```

### 问题
1. **无效内容占比极高**：每节视频开场大量时间是设备调试（"声音行吗"）、弹幕互动、闲聊喝茶、读SC打赏，正课内容往往在每节视频的中后段才开始，前30%~50%几乎无价值
2. **ASR识别错误严重**：口语化表达 + 专业术语（B1/B2/活跃市值/暴力K）识别率低，错别字多，语义失真
3. **无段落无标点**：连续输出长文本，无法区分话题边界
4. **语义噪音高**：讲师随口聊天的句子和核心知识点混在一起，无法区分

### 对比：高质量文稿的样子（0219/0220 人工整理版）
```
任何资金想做大必须控制回撤，回撤就是要快速止损，果断放飞，然后和仓位管理。
你把这三招做会了，你会有很多踏空，但是你会发现你的净值曲线肯定会往东北方向发展。
...
无论你是大资金小资金，如果你想资金做大，记住：任何资金想做大必须控制回撤。
```

→ 有标点、有段落、可读性强，Agent 可以直接提取有效规则。

### 结论
**垃圾进，垃圾出。ASR直出文稿不能作为分析输入。**  
必须先对原始文稿进行预处理，过滤无效内容，再交给分析Agent。

## 三、问题二：处理逻辑——按"时间段"而非"主题"切割

### 症状
当前流程是把视频按录制顺序分成"第1部分、第2部分...第N部分"，分别分析后汇总。

### 问题
1. **知识点被时间切割打散**：同一个概念（如"B2买点识别"）可能横跨第2、3、4部分，分段分析后无法整合
2. **开场/闲聊/正课混在一起**：Agent没有被要求识别和跳过无效段落，被迫对"弹幕互动"等内容生成分析
3. **汇总时无法重组碎片**：各段的JSON分别提交，最终汇总 Agent 没有能力把不同部分里的同一主题碎片重新组织成完整知识体系

### 应该的做法
按**知识主题**而非时间段处理：
- 先识别全视频的主题结构（开场/正课/案例/Q&A）
- 只对"正课"部分做深度分析
- 按主题聚合，不按时间段聚合

## 四、问题三：输出格式——knowledge_base.json 结构设计失当

### 症状
以"仓位管理"视频的实际输出为例：

```json
"技术规则": [
  { "规则": "仓位", "解读": "出现3次" },
  { "规则": "短线", "解读": "出现2次" },
  { "规则": "白酒", "解读": "出现17次" },
  { "规则": "指数", "解读": "出现10次" },
  { "规则": "白酒", "解读": "出现17次" }
]
```

以"击穿对手盘"视频的实际输出为例：

```json
"技术规则": [
  { "规则": "击穿对手盘核心逻辑" },
  { "规则": "关键点位分析" },
  { "规则": "资金管理" }
]
```

### 问题
1. **词频统计不是规则提取**：Agent 拿到碎片输入后，退化为统计关键词出现次数，而非提取可执行规则
2. **规则字段是空标题**：只有名称，没有内容。"击穿对手盘核心逻辑"写的是标题，不是规则
3. **关键观点字段是目录，不是观点**：
   ```
   "关键观点": ["第一部分: 复盘本周操作与盘面", "第二部分: z哥使用方法"]
   ```
   这是视频章节目录，不是提炼出来的核心观点
4. **无质量验证机制**：空内容、目录、词频计数都能通过，没有任何验证规则是否有实质内容

### 应该的输出格式
每条规则必须包含：
- **条件**：什么情况下触发
- **动作**：具体怎么操作
- **背景**：为什么这样做（可选）

例如：
```json
{
  "规则": "波段止损设置",
  "条件": "持仓跌破日线白线（5日均线）3%以下",
  "动作": "立即止损出场，不等反弹",
  "背景": "破白线意味着趋势改变，继续持有风险大于收益"
}
```

## 六、优化方案建议

### 推荐流程（参考0219/0220的成功案例）

```
原视频
  ↓
Step 1: 高质量文稿生成
  - 使用更好的ASR模型（或人工校对）
  - 输出：带标点、带段落、可读的完整文字稿

Step 2: 文稿预处理（清洗）
  - 识别并剔除：开场设备调试、弹幕互动、SC读单、闲聊
  - 保留：正课讲解、案例分析、规则总结
  - 输出：纯净的"正课文稿"

Step 3: 主题结构识别
  - 分析正课文稿，识别主题段落
  - 标注：核心概念 / 操作规则 / 案例演示 / 条件判断
  - 输出：带主题标注的结构化文稿

Step 4: 规则提取（分析Agent核心工作）
  - 对每个主题段落提取：条件+动作+背景
  - 验证每条规则是否有实质内容（禁止空标题）
  - 输出：结构化规则JSON

Step 5: 知识库整合
  - 把同一主题的规则跨视频合并
  - 按战法体系组织（不按视频时间顺序）
  - 输出：可用的知识库.md文件
```

### 关键验证标准（质量门控）

分析Agent在输出前必须验证：

1. **规则完整性检查**：每条规则必须同时包含"触发条件"和"具体动作"，缺一不可
2. **内容实质性检查**：禁止输出纯标题（如"核心逻辑"、"关键点位分析"），必须有具体内容
3. **词频统计禁止**：技术规则字段禁止出现"XX出现N次"的格式
4. **正课覆盖率检查**：提取的规则应能对应到文稿中的具体段落
