# 选股复盘总索引

## 目的

通过持续的"选股→验证→归因→认知更新"循环，积累市场判断经验，强化知识库战法，提高选股命中率。

## 运作规则

1. **每日选股时**：记录当时的判断逻辑（买入理由、风险点、预期）
2. **次日收盘后**：验证结果，对错均需归因分析
3. **每周日**：进行周度总结，提取规律更新知识库
4. **认知更新**：每次复盘发现的新规律，写入 `knowledge/` 目录的战法文档

## 复盘模板

```
# YYYY-MM-DD 选股复盘

## 一、当日选股记录
（启动K + 砖型图的原始标的 + 当时的判断逻辑）

## 二、次日验证结果
（实际涨跌幅 vs 预期 → 对/错/待观察）

## 三、归因分析
### 判断正确
### 判断失误
### 待观察

## 四、准确率统计
- 本日选股命中率：X%
- 累计命中率（滚动计算）

## 五、认知更新
（发现的新规律/需要更新的战法）
```
