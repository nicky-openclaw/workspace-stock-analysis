# 选股复盘总索引

## 目的

通过持续的"选股→验证→归因→认知更新"循环，积累市场判断经验，强化知识库战法，提高选股命中率。

## 运作规则

1. **每日选股时**：记录当时的判断逻辑（买入理由、风险点、预期）
2. **次日收盘后**：验证结果，对错均需归因分析
3. **每周日**：进行周度总结，提取规律更新知识库
4. **认知更新**：每次复盘发现的新规律，写入对应的战法文件（不是新建文件）

## 分类原则

| 内容 | 存放位置 |
|------|---------|
| 复盘记录（对错验证原始数据） | memory/patrol/review/YYYY-MM-DD_review.md |
| 从复盘提炼的规律性认知 | → 更新到 knowledge/战法/ 对应的战法文件 |
| 复盘索引 | memory/patrol/review/index.md |
