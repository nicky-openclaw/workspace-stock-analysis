### 2. 复盘数据错误
**问题**：复盘用的涨幅数据错误

**错误做法**：
```python
# ❌ 错误：用实时API
url = f'https://qt.gtimg.cn/q={market}{code}'
# 返回的是实时价格，不是收盘价！
```

**正确做法**：
```python
# ✅ 正确：用K线获取收盘价
url = f'https://web.ifzq.gtimg.cn/appstock/app/fqkline/get?param={market}{code},day,,,5,qfq'
klines = data['data'][f'{market}{code}']['qfqday']
yesterday_close = float(klines[-2][2])  # 昨日收盘
today_close = float(klines[-1][2])    # 今日收盘
change = (today_close - yesterday_close) / yesterday_close * 100
```
