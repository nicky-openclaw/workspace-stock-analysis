# 2026-03-03 数据错误教训

## 今日错误事件

**问题**：复盘用的涨幅数据错误
- 第一次发的复盘用的是15:05实时价格，不是收盘价
- 被用户发现并批评

## 错误的数据获取方式（不要用！）

```python
# ❌ 错误：用实时API获取的价格
url = f'https://qt.gtimg.cn/q={market}{code}'
# 这个返回的是实时价格，不是收盘价！
```

## 正确的数据获取方式

### 必须用K线数据计算涨幅！

```python
# ✅ 正确：用K线获取收盘价，计算涨幅
import requests

def get_change_percent(code):
    market = 'sh' if code.startswith('6') else 'sz'
    url = f'https://web.ifzq.gtimg.cn/appstock/app/fqkline/get?param={market}{code},day,,,5,qfq'
    resp = requests.get(url, timeout=5)
    data = resp.json()
    
    klines = data['data'][f'{market}{code}']['qfqday']
    
    yesterday_close = float(klines[-2][2])  # 昨日收盘价
    today_close = float(klines[-1][2])      # 今日收盘价
    
    change = (today_close - yesterday_close) / yesterday_close * 100
    return change

# 涨幅 = (今日收盘价 - 昨日收盘价) / 昨日收盘价 * 100
```

### 关键点

1. **必须用K线数据**：用 `/appstock/app/fqkline/get` 接口
2. **必须用收盘价**：K线数据的第3列（索引2）是收盘价
3. **计算公式**：(今日收盘价 - 昨日收盘价) / 昨日收盘价 * 100
4. **不能用实时API**：实时API返回的是实时价格，不是收盘价
