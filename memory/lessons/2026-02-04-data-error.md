# 2026-02-04 数据错误教训

## 事件
股票数据与实际不符

| 股票 | 文档写 | 实际 | 错误原因 |
|------|--------|------|----------|
| 兴业银锡（000426） | 跌7% | 涨3.79% | 使用缓存数据 |
| 航天发展（000547） | 涨停+9.99% | 涨0.12% | 使用过时数据 |
| 招金黄金（000506） | 跌3.29% | 跌5.77% | API字段误用 |

## 教训
1. 不能使用缓存数据
2. API字段含义会随上下文变化（非交易时段f46=开盘价≠收盘价）
3. 财务数据必须验证时间戳
4. 重要数据必须交叉验证
