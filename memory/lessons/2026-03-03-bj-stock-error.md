## 问题描述

特瑞斯（920014）是北交所股票，涨停+30%，但未被选入今日选股列表。

原因：API无法获取北交所数据

## 问题原因

1. **腾讯API**：不支持北交所（920开头）股票，返回空值
2. **东方财富API**：连接失败

## 解决方案

### 方案1：使用浏览器获取北交所数据

北交所行情页面：https://quote.eastmoney.com/center/gridlist.html#bj_a_board

浏览器可以正常获取数据。

### 方案2：修改代码处理北交所

北交所股票代码特点：
- 9开头（920xxx）
- 需要用不同的市场代码

### 代码修改示例

```python
def get_market(code):
    """判断市场代码"""
    if code.startswith('6'):
        return 'sh'
    elif code.startswith('0') or code.startswith('3'):
        return 'sz'
    elif code.startswith('9'):
        # 北交所 - 用浏览器获取
        return 'bj'
    else:
        return 'sz'
```

## 教训

1. 选股时不能只处理沪深A股
2. 北交所数据需要单独处理
3. API失败时用浏览器备用
