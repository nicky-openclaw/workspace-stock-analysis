## 🏗️ 执行架构（子代理模式）

**原则：数据落文件，结果传主Agent，主Agent只做协调+最终输出**

```
主Agent（协调者）
├── Step 1 → 子代理A：图片识别（串行逐张，N张图=调用N次image工具）→ 输出 b1_stocks.json
├── Step 2 → 子代理B：K线数据拉取 → 输出 b1_kline.json
├── Step 3 → 子代理C：指标计算   → 输出 b1_indicators.json
├── Step 4 → 子代理D：评分筛选   → 输出 b1_scores.json
└── Step 5 → 主Agent读取结果 → 输出 TOP5 + K线分析 + 明日交易建议
```

**文件路径**：`~/.openclaw/workspace-stock-analysis/b1_output/`

## 📋 执行步骤

### Step 1 — 图片识别（并发子代理模式）

**任务**：识别所有图片中的股票代码和名称

**⚠️ 多图识别铁律（2026-03-09）**：
- image skill 传入 `images` 数组时**只处理第1张**，其余全部忽略
- **必须为每张图片单独 spawn 一个子代理**，每个子代理只识别1张图
- N 张图 → 同时 spawn N 个子代理（并发）→ 等所有子代理完成 → 汇总去重
- 禁止使用 `images=[...]` 数组批量传入多张图
- 禁止串行识别（逐张等待太慢）

**并发执行流程**：
```
主Agent收到 N 张图
→ spawn 1个子代理A
→ 子代理A 串行调用 image 工具 N 次（每次1张）
→ 汇总去重 → 写入 b1_stocks.json
```

- 每张图独立识别，不能遗漏
- 输出去重后的完整代码清单
- 标注每只股票的市场前缀（sh/sz/bj）

**输出文件**：`b1_output/b1_stocks.json`
```json
{
  "total": 331,
  "date": "2026-03-06",
  "stocks": [
    {"code": "688112", "name": "鼎阳科技", "prefix": "sh"},
    {"code": "002597", "name": "金禾实业", "prefix": "sz"}
  ]
}
```

### Step 2 — K线数据拉取（子代理B）

**任务**：读取 b1_stocks.json，批量拉取120日K线

**API**：`https://web.ifzq.gtimg.cn/appstock/app/fqkline/get?param={prefix}{code},day,,,120,qfq`

**必须获取字段**：
- 120日日K线（日期、开、高、低、收、量）
- 当日 qt 字段（实时行情补充）

**北交所处理**：调用 agent-browser skill，爬取东方财富/同花顺数据

**输出文件**：`b1_output/b1_kline.json`（不回传给主Agent，直接写文件）

---

### Step 2 强制校验（优化为并行调用）

> ⚠️ **2026-03-09 优化**：同时调用两个接口，一次获取全部数据

**正确做法**：K线接口（算均线）+ 实时接口（直接获取涨跌幅），**并行执行**

**关键：实时API本身包含涨跌幅，直接使用！**
```
腾讯API返回字段：
- 字段3: 当前价格
- 字段4: 昨收
- 字段32: 涨跌幅%（直接使用，无需计算！）
- 字段31: 涨跌额
```

**禁止**：自己用K线收盘价计算涨幅 ✅
**正确**：直接取实时API的涨跌幅字段 ✅

**数据源组合**：

| 用途 | 数据源 | 调用方式 |
|------|--------|---------|
| 计算MA均线/量比/位置 | 腾讯K线API（akshare stock_zh_a_hist_tx） | 获取120日K线 |
| 获取今日实时价格/涨跌幅 | 腾讯实时API（qt.gtimg.cn） | 实时调用 |

**腾讯实时API调用**：
```bash
curl "https://qt.gtimg.cn/q=sh601339"
```

**禁止**：先检测再切换的低效做法 ✅

**检查点**：
- [ ] **Step 2 同时调用了K线API和实时API？**（并行获取，无需检测切换）
- [ ] 涨跌幅是用 (今日收盘-昨日收盘)/昨日收盘 计算的吗？

### Step 3 — 指标计算（必须包含）

**必须计算**：
| 指标 | 公式 |
|------|------|
| MA5/10/20 | 标准均线 |
| J值 | KDJ公式 |
| RSI3 | Wilder平滑公式 |
| **振幅** | **(max(highs_20)-min(lows_20))/min(lows_20)×100** |
| **缩量** | **今日VOL < max(VOL_20) × 0.416** |
| 白线/黄线 | EMA(EMA(C,10),10) / (MA14+MA28+MA57+MA114)/4 |（子代理C）

**任务**：读取 b1_kline.json，计算所有技术指标

**必须计算**：
| 指标 | 公式来源 |
|------|---------|
| MA5、MA10、MA20 | indicators/library.py |
| J值（KDJ） | indicators/library.py |
| RSI（14日） | indicators/library.py |
| 今日量 / 昨日量 / 20日均量 / 20日最低量 | indicators/library.py |
| MA20今日值 vs 昨日值（方向判断） | 直接比较 |
| 今日收盘 vs MA20（位置判断） | 百分比偏差 |
| 近20日是否出现过倍量柱 | 最高量 vs 均量 ≥ 2倍 |

**输出文件**：`b1_output/b1_indicators.json`

### Step 4 — 综合评分（子代理D）

#### 🔴 硬淘汰条件（不满足直接排除，不进入评分）
| 条件 | 规则 |
|------|------|
| 白线在黄线之下 | 趋势白线(EMA(EMA(C,10),10)) < 趋势黄线((MA14+MA28+MA57+MA114)/4) → 淘汰 |
| 当日跌破白线 | 今日收盘 < 趋势白线 → 淘汰 |

#### 📊 五层综合评分（满分100分）

**第一层：趋势质量（30分）**
| 指标 | 分数 | 条件 |
|------|------|------|
| 白线≥黄线 | +10分 | EMA(EMA(C,10),10) ≥ (MA14+MA28+MA57+MA114)/4 |
| MA20方向向上 | +10分 | 今日MA20 > 昨日MA20 |
| 双线确认 | +10分 | 白线≥黄线 且 MA20向上 |

**第二层：量能质量（25分）**
| 指标 | 分数 | 条件 |
|------|------|------|
| 地量回调（最优信号） | +25分 | 今日量 < 20日最低量 × 1.2 |
| 缩量回调 | +15分 | 今日量 < 昨日量（不满足地量时取） |
| 近20日出现过倍量柱 | +10分 | 近20日内最大量 ≥ 均量 × 2 |

> 量能层最多取25分（地量和缩量不叠加，取最高档）

**第三层：买点质量（30分）**
| 指标 | 分数 | 条件 |
|------|------|------|
| B1完整触发（最优） | +30分 | J<14 + RSI<23 + 缩量 全部满足 |
| J值超卖 | +15分 | J < 14（B1未完整触发时） |
| RSI超卖 | +10分 | RSI < 23（B1未完整触发时） |
| 位置在黄线附近 | +5分 | 今日收盘在MA20的 ±3% 以内 |

> 买点层：B1完整触发直接+30，否则各项单独累加，上限30分

**第四层：涨幅确认（15分）**
| 指标 | 分数 | 条件 |
|------|------|------|
| 强势确认 | +15分 | 今日涨幅 5%~9.9% |
| 中等确认 | +8分 | 今日涨幅 2%~5% |
| 弱确认 | +3分 | 今日涨幅 0%~2% |
| 涨停 | +15分 | 涨幅 ≥ 9.9% |

**（可选加分）主力证据层（最多+10分溢出加分，可突破100分上限至110）**
| 指标 | 分数 | 条件 |
|------|------|------|
| 近5日出现关键K/暴力K | +5分 | 单日涨幅≥5%+放量 |
| 近20日三门重炮 | +5分 | 连续3日倍量 |

**输出文件**：`b1_output/b1_scores.json`

## 三级筛选体系（v4.0 新增 - 2026-03-12）

### 背景
当B1完整触发的股票超过5只时，需要二级+三级筛选区分优先级。

### 一级筛选：B1五条件（基础分77分）
| 检查项 | 满足条件 | 分数 |
|--------|----------|------|
| 白线≥黄线 | 白线≥黄线 | +10 |
| J<13 | J值<13 | +12 |
| RSI3<23 | RSI3<23 | +10 |
| 振幅≥15% | 近20日振幅≥15% | +10 |
| 缩量 | VOL<20日最高量×0.416 | +15 |
| B1完整触发 | 五条件全满足 | +20 |

### 二级筛选：位置+趋势+量能（30分满分）
| 检查项 | 条件 | 分数 |
|--------|------|------|
| 黄线附近 | 股价在黄线±5% | +15 |
| 白线附近 | 股价在白线±3% | +10 |
| 站上白线 | 股价在白线+3%~8% | +5 |
| 趋势强 | 白线-黄线差>5% | +5 |
| 地量 | VOL<20日最低量×1.5 | +10 |
| 缩量 | VOL<20日最高量×0.416 | +5 |

### 三级筛选：股性+弹性（10分满分）
| 检查项 | 条件 | 分数 |
|--------|------|------|
| 涨停基因 | 20日内有涨停 | +5 |
| 回调深度 | 从20日高点回调>10% | +3 |
| 白线斜率 | 10日涨幅>5% | +2 |

### 评分公式
**总分 = 一级分(77) + 二级分(30) + 三级分(10) = 117分满分**

### 排序规则
1. 一级分降序
2. 一级分相同 → 二级分降序
3. 二级分相同 → 三级分降序

### Step 5 — 主Agent输出（v3.0）

**主Agent读取**：`b1_output/b1_scores.json`（只读TOP5，不加载全量数据）

**Step 5.1 关键指标表**：

| 排名 | 代码 | 名称 | 涨幅% | 白线 | 黄线 | 白线>黄线 | J值 | RSI3 | 量比 | B1触发 | 评分 |
|------|------|------|-------|------|------|----------|-----|------|------|--------|------|

**Step 5.2 K线详细形态分析（B1专属）**：

B1核心逻辑：超卖反弹 → 低位缩量 + J/RSI超卖 + 关键K异动

对TOP5每只股票分析：
- **B1触发条件检查**：
  - [ ] 白线在黄线之上
  - [ ] 缩量回调（VOL < 20日最高量 × 0.416）
  - [ ] J值 < 13（超卖）
  - [ ] RSI3 < 23（超卖）
  - [ ] 振幅 ≥ 15%（近期异动）
- 价格：最新价、5日涨幅
- 趋势：白线、黄线位置
- 量能：地量信号、量比
- 评分明细

**Step 5.3 明日交易决策checklist（B1专属）**：

| 检查项 | 股票A | 股票B |
|--------|-------|-------|
| B1五条件全满足？ | ✅/❌ | ✅/❌ |
| 竞价量比>1.5？ | 明日看 | 明日看 |
| 关键K位置？ | / | / |
| 止损位=今日最低价？ | ✅ | ✅ |
| 板块效应？ | 有/无 | 有/无 |

**B1交易要点**：
- 买入：次日开盘买入
- 止损：买入当根K线最低价
- 适用：任何市场环境，盈亏比最高
