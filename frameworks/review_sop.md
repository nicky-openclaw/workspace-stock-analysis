## 一、执行规范（铁律）

1. **数据来源**：必须从 `patrol/YYYYMMDD/` 目录读取上一个交易日的选股报告
   - 不得凭记忆或猜测股票列表
   - 目录格式：`patrol/20260316/启动K选股报告_20260316.md` + `砖型图选股报告_20260316.md`

2. **数据获取**：使用 **agent-browser** 批量获取收盘价和涨跌幅
   - eastmoney_financial_data skill 额度仅用于选股筛选，复盘禁止使用
   - 备用方案：腾讯API qt.gtimg.cn

3. **执行时间**：每个交易日 15:30 收盘后自动触发

## 二、复盘分析框架

每只股票需要回答以下问题：

### 2.1 基础数据
- 昨日涨幅 / 是否涨停
- 今日开盘方式（高开 / 平开 / 低开）
- 今日收盘涨跌幅
- 今日成交量 vs 昨日（放量 / 缩量）
- 今日主力资金净流向

### 2.2 归因分析（核心）

**情形A：昨日涨停 → 今日继续上涨**
需要判断：
- 是否有持续性题材（政策/业绩/行业催化）
- 是否有新消息面支撑
- 板块整体是否继续强势
- 结论：**题材延续，可继续关注**

**情形B：昨日涨停 → 今日回落/低开下杀**
需要判断：
- 是否是**诱多出货**（高开后快速下杀，量能放大）
- 是否是**题材一日游**（无持续催化，情绪退潮）
- 是否是**大盘拖累**（个股本身没问题，大盘弱势）
- 龙虎榜：昨日买入方是游资还是机构
- 结论：**出货 / 一日游 / 正常回调**

**情形C：昨日大涨未涨停 → 今日走势**
- 涨幅是否小于大盘跌幅（抗跌 = 强势）
- 是否缩量回调（健康洗盘）
- 结论：**强势延续 / 跟跌弱势**

### 2.3 判断依据优先级
1. **开盘方式** — 最直接反映主力意图
2. **量能变化** — 放量下跌=出货，缩量回调=洗盘
3. **消息面** — 有无新催化剂
4. **板块联动** — 板块整体强弱
5. **龙虎榜** — 昨日资金性质（游资 vs 机构）

## 四、常见问题归因

| 现象 | 可能原因 | 判断方法 |
|------|---------|---------|
| 高开低走 | 主力出货 / 散户追高 | 看龙虎榜买方性质 |
| 低开高走 | 主力洗盘 / 吸筹 | 看尾盘是否拉升 |
| 平开震荡 | 多空分歧 | 看量能和方向 |
| 缩量回调 | 正常调整 | 看是否守住关键均线 |
| 放量下跌 | 出货信号 | 看是否跌破支撑 |
| 涨停被炸 | 大单砸盘 / 情绪崩塌 | 看封单量变化 |
