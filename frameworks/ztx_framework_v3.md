# 砖型图框架 SOP v3.2

> 更新日期：2026-03-13
> 版本：v3.3（统一板块数据获取流程，对齐AGENTS.md）

---

## 框架概述

砖型图选股框架，超短线交易模式。

---

## 触发条件

用户发送条件股截图并提及"砖型图"或"砖形图"时触发。

---

## 评分体系

- 涨停30分
- 涨幅5-9% 15分
- J值超卖10分
- MA20向上10分
- 均线多头排列15分
- 砖型图走强20分
- 砖型值>100 10分
- B1信号25分
- B2信号20分
- 放量15分
- 热门概念5分
- 龙头概念10分
- 硬淘汰：白线＜黄线

---

## 执行流程

1. **图片识别**：使用 minimax-understand-image skill（可能有多张截图）
2. **K线拉取**：ztx_step2_fetch.py
3. **指标计算**：ztx_step3_calc.py
4. **综合评分**：ztx_step4_score.py
5. **板块效应分析**：
   - 运行 `python3 scripts/sector_analysis_v4.py --framework ztx` 获取个股所属板块和资金流
   - **数据获取优先级（v3.3）：**
     1. 腾讯API → 个股涨跌幅
     2. **eastmoney_financial_data skill** → 行业+板块涨跌+主力净额
     3. agent-browser → 补齐行业（备用）
     4. QVeris → 保底

   **⚠️ Step 5.1（强制检查点）：验证板块数据**
   - 板块分析完成后，必须读取 `ztx_output/sector_analysis.json`
   - 检查每只股票的 `sector_change_pct` 字段是否非空
   - 若字段为空，立即用 agent-browser 打开东方财富页面手动获取
   - **板块数据未验证通过之前，禁止进入第6步**

6. **输出报告**：按格式输出
7. **清理截图**：删除 patrol 目录图片

### 1. 涨停TOP5
评分前5只（包含涨停的股票）

### 2. 非涨停TOP5
评分前5只（不包含涨停的股票）

### 3. 关键指标表（涨停TOP5）
| 字段 |
|------|
| 代码 |
| 名称 |
| 白线 |
| 黄线 |
| 白>黄 |
| 涨幅 |
| 砖型值 |
| J值 |
| RSI |
| B1 |
| B2 |
| 量比 |
| 评分 |

（必须包含全部5只）

### 4. 关键指标表（非涨停TOP5）
同上，必须包含全部5只

### 5. K线详细形态分析（涨停TOP5）

每只股票格式（4行，纯正文不加粗）：

第一行：白线/黄线数据，间距，MA状态，位置，放量，涨跌
第二行：RSI｜J值｜涨幅（纯数字，用 ｜ 分隔）
第三行：评分构成：关键加分项+分值（≤6项，| 分隔）
第四行：⚠️ 风险（🔴 标记RSI>85或极高风险标的）

**规则**：全文不加任何 **加粗**，不用"趋势："、"量能："等标签前缀；数值全保留，文字精简。（必须包含全部5只）

### 6. K线详细形态分析（非涨停TOP5）

同上格式，必须包含全部5只。

### 7. 板块效应分析
每只股票包含：
| 字段 | 说明 |
|------|------|
| 所属行业 | 申万/同花顺行业 |
| 所属概念 | 热门题材概念（如有） |
| 板块走势 | 强势/震荡/弱势 |
| 板块主力净流入 | 金额 |
| 板块助攻 | 强/中/弱/无 |

**板块数据查询优先级（与执行流程 Step5 一致）：**
1. 腾讯API → 个股涨跌幅
2. **eastmoney_financial_data skill** → 行业+板块涨跌+主力净额
3. agent-browser → 补齐行业（备用）
4. QVeris → 保底

**查不到时的处理：**
- 标注为"细分行业，需人工确认"
- 可通过股票详情页的"所属板块"查看关联概念
- 必要时查询概念资金流补充

附：当日热点板块/资金流入前5

## 注意事项

1. 必须使用 minimax-understand-image skill 识别图片
2. 可能有多张截图，需逐张识别后合并去重
3. 禁止跳过任何输出字段
4. 关键指标表必须包含全部10只（涨停TOP5+非涨停TOP5）
5. K线详细形态分析必须逐只分析，不能省略
6. 任务完成后清理 patrol 目录截图
7. 每次分析必须有风险提示
