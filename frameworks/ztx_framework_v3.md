# 砖型图框架 SOP v3.2

> 更新日期：2026-03-13
> 版本：v3.2（新增板块效应分析一键脚本）

---

## 框架概述

砖型图选股框架，超短线交易模式。

---

## 触发条件

用户发送条件股截图并提及"砖型图"或"砖形图"时触发。

---

## 评分体系

- 涨停30分
- 涨幅5-9% 15分
- J值超卖10分
- MA20向上10分
- 均线多头排列15分
- 砖型图走强20分
- 砖型值>100 10分
- B1信号25分
- B2信号20分
- 放量15分
- 热门概念5分
- 龙头概念10分
- 硬淘汰：白线＜黄线

---

## 执行流程

1. **图片识别**：使用 minimax-understand-image skill（可能有多张截图）
2. **K线拉取**：ztx_step2_fetch.py
3. **指标计算**：ztx_step3_calc.py
4. **综合评分**：ztx_step4_score.py
5. **板块效应分析**：
   - 运行 `python3 scripts/ztx_sector_analysis.py` 获取个股所属板块和资金流
   - 通过浏览器打开 https://data.eastmoney.com/bkzj/hy.html 查询板块涨跌幅/主力净流入
   - 手动补充到 sector_analysis.json
6. **输出报告**：按格式输出
7. **清理截图**：删除 patrol 目录图片

---

## 输出格式（必须完整）

### 1. 涨停TOP5
评分前5只（包含涨停的股票）

### 2. 非涨停TOP5
评分前5只（不包含涨停的股票）

### 3. 关键指标表（涨停TOP5）
| 字段 |
|------|
| 代码 |
| 名称 |
| 白线 |
| 黄线 |
| 白>黄 |
| 涨幅 |
| 砖型值 |
| J值 |
| RSI |
| B1 |
| B2 |
| 量比 |
| 评分 |

（必须包含全部5只）

### 4. 关键指标表（非涨停TOP5）
同上，必须包含全部5只

### 5. K线详细形态分析（涨停TOP5）
逐只分析每只的技术面：
- 趋势（白线/黄线位置、均线排列）
- 量能（放量倍数、量能形态）
- 砖型值（今日值/昨日值/变化）
- B信号（B1/B2触发情况）
- 风险提示

（必须包含全部5只）

### 6. K线详细形态分析（非涨停TOP5）
逐只分析每只的技术面，必须包含全部5只

### 7. 板块效应分析
每只股票包含：
| 字段 | 说明 |
|------|------|
| 所属行业 | 申万/同花顺行业 |
| 所属概念 | 热门题材概念（如有） |
| 板块走势 | 强势/震荡/弱势 |
| 板块主力净流入 | 金额 |
| 板块助攻 | 强/中/弱/无 |

**板块数据查询优先级：**
1. 行业资金流（东方财富 > 数据中心 > 行业资金流）
2. 概念资金流（同上 > 概念资金流）
3. 地域板块资金流

**查不到时的处理：**
- 标注为"细分行业，需人工确认"
- 可通过股票详情页的"所属板块"查看关联概念
- 必要时查询概念资金流补充

附：当日热点板块/资金流入前5

### 8. 明日交易决策 Checklist
| 检查项 |
|--------|
| 白线>黄线 |
| 竞价量比>2 |
| 板块效应 |
| 止损位(-7%) |

## 注意事项

1. 必须使用 minimax-understand-image skill 识别图片
2. 可能有多张截图，需逐张识别后合并去重
3. 禁止跳过任何输出字段
4. 关键指标表必须包含全部10只（涨停TOP5+非涨停TOP5）
5. K线详细形态分析必须逐只分析，不能省略
6. 任务完成后清理 patrol 目录截图
7. 每次分析必须有风险提示

## K线详细形态写作规范

**格式**（每只股票4行）：
```
### N. 股票名称（代码）评分 | 涨幅 | 启动类型

白线/黄线数据，间距，MA状态，位置，放量，涨跌
RSI｜J值｜涨幅（纯数字独立一行）
评分构成：关键加分项+分值（≤6项，|分隔）
⚠️ 风险（🔴标记RSI>85或极高风险）
```

**规则**：
- 全文不加 `**加粗**`，不用 `趋势：`、`量能：` 等标签前缀
- RSI/J值/涨幅 独立一行，纯数字，用 `｜` 分隔
- 风险提示独立一行，🔴 用于 RSI>85 标的
- 数值全保留，文字精简
